# 本地方法详解

## 什么是本地方法？

本地方法是指**用非Java语言实现的方法**，通常用 C、C++ 编写，通过 JNI（Java Native Interface）与 Java 代码交互。

在 Java 代码中，本地方法用 `native` 关键字标识。

## 常见的本地方法例子

### 1. **Object 类中的本地方法**

```java
public class Object {
    // 获取对象的哈希码
    public native int hashCode();
    
    // 返回对象的运行时类
    public final native Class<?> getClass();
    
    // 克隆对象
    protected native Object clone() throws CloneNotSupportedException;
    
    // 唤醒等待的线程
    public final native void notify();
    public final native void notifyAll();
    
    // 线程等待
    public final native void wait(long timeout) throws InterruptedException;
}
```

### 2. **Thread 类中的本地方法**

```java
public class Thread {
    // 启动线程
    private native void start0();
    
    // 检查线程是否存活
    public final native boolean isAlive();
    
    // 设置线程优先级
    private native void setPriority0(int newPriority);
    
    // 当前线程让出CPU
    public static native void yield();
    
    // 线程睡眠
    public static native void sleep(long millis) throws InterruptedException;
    
    // 获取当前线程
    public static native Thread currentThread();
}
```

### 3. **System 类中的本地方法**

```java
public final class System {
    // 数组拷贝（高效）
    public static native void arraycopy(Object src, int srcPos,
                                       Object dest, int destPos,
                                       int length);
    
    // 获取当前时间（毫秒）
    public static native long currentTimeMillis();
    
    // 获取纳秒时间
    public static native long nanoTime();
    
    // 返回对象的identityHashCode
    public static native int identityHashCode(Object x);
}
```

### 4. **Class 类中的本地方法**

```java
public final class Class<T> {
    // 通过类名获取Class对象
    private static native Class<?> forName0(String name, 
                                           boolean initialize,
                                           ClassLoader loader,
                                           Class<?> caller);
    
    // 判断是否是某个类的实例
    public native boolean isInstance(Object obj);
    
    // 判断是否是某个类的子类
    public native boolean isAssignableFrom(Class<?> cls);
    
    // 获取类的修饰符
    public native int getModifiers();
}
```

### 5. **FileInputStream 中的本地方法**

```java
public class FileInputStream extends InputStream {
    // 打开文件
    private native void open0(String name) throws FileNotFoundException;
    
    // 读取字节
    public native int read() throws IOException;
    
    // 读取字节数组
    private native int readBytes(byte b[], int off, int len) throws IOException;
    
    // 跳过字节
    public native long skip(long n) throws IOException;
    
    // 关闭文件
    private native void close0() throws IOException;
}
```

### 6. **Unsafe 类（底层操作）**

```java
public final class Unsafe {
    // 分配内存
    public native long allocateMemory(long bytes);
    
    // 释放内存
    public native void freeMemory(long address);
    
    // 直接操作内存
    public native byte getByte(long address);
    public native void putByte(long address, byte x);
    
    // CAS操作（Compare And Swap）
    public final native boolean compareAndSwapInt(Object o, 
                                                  long offset,
                                                  int expected, 
                                                  int x);
    
    // 线程park/unpark
    public native void park(boolean isAbsolute, long time);
    public native void unpark(Object thread);
}
```

## 实际使用示例

### 示例 1：调用 System.arraycopy()

```java
public class NativeExample {
    public static void main(String[] args) {
        int[] src = {1, 2, 3, 4, 5};
        int[] dest = new int[5];
        
        // 调用本地方法arraycopy
        System.arraycopy(src, 0, dest, 0, 5);
        
        // dest现在是 {1, 2, 3, 4, 5}
    }
}
```

**执行流程：**
```
Java代码调用
    ↓
System.arraycopy() [native方法]
    ↓
本地方法栈
    ↓
JNI接口
    ↓
C/C++实现的本地代码
    ↓
直接操作内存完成数组拷贝
```

### 示例 2：Thread.sleep()

```java
public class SleepExample {
    public static void main(String[] args) throws InterruptedException {
        System.out.println("开始");
        
        // 调用本地方法sleep
        Thread.sleep(1000);  // 底层是native方法
        
        System.out.println("1秒后");
    }
}
```

### 示例 3：自定义本地方法

```java
public class HelloJNI {
    // 声明本地方法
    public native void sayHello();
    
    // 加载本地库
    static {
        System.loadLibrary("hello"); // 加载libhello.so或hello.dll
    }
    
    public static void main(String[] args) {
        new HelloJNI().sayHello();
    }
}
```

对应的 C 代码（hello.c）：
```c
#include <jni.h>
#include <stdio.h>
#include "HelloJNI.h"

JNIEXPORT void JNICALL Java_HelloJNI_sayHello(JNIEnv *env, jobject obj) {
    printf("Hello from C!\n");
}
```

## 为什么需要本地方法？

### 1. **访问操作系统功能**
```java
// Java无法直接访问操作系统API
// 需要通过本地方法调用Windows/Linux/macOS的系统调用
FileInputStream.open0()  // 调用操作系统的文件打开API
```

### 2. **性能优化**
```java
// 某些操作用C/C++实现更高效
System.arraycopy()  // C实现的内存拷贝比Java循环快得多
```

### 3. **与现有C/C++库交互**
```java
// 复用已有的C/C++库（如图形库、数学库）
// OpenGL、DirectX等图形库
// 科学计算库（BLAS、LAPACK）
```

### 4. **硬件访问**
```java
// 直接访问硬件（如显卡、USB设备）
// Java层无法直接操作硬件
```

## 本地方法栈的工作示意图

```
┌─────────────────────────────────┐
│      Java虚拟机栈               │
│  ┌─────────────────────┐        │
│  │ Java方法栈帧        │        │
│  │ - sayHello()        │        │
│  └─────────────────────┘        │
│           ↓ 调用native方法       │
└─────────────────────────────────┘
            ↓
┌─────────────────────────────────┐
│      本地方法栈                 │
│  ┌─────────────────────┐        │
│  │ Native方法栈帧      │        │
│  │ - Java_HelloJNI_... │        │
│  └─────────────────────┘        │
└─────────────────────────────────┘
            ↓
┌─────────────────────────────────┐
│      本地代码（C/C++）          │
│  - 操作系统API调用              │
│  - 硬件访问                     │
│  - 高性能计算                   │
└─────────────────────────────────┘
```

## HotSpot中的实现

在 **HotSpot 虚拟机**中，Java 虚拟机栈和本地方法栈是**合二为一**的：

```
┌─────────────────────────────────┐
│   HotSpot的栈（合并实现）       │
├─────────────────────────────────┤
│  Java方法栈帧                   │
├─────────────────────────────────┤
│  Native方法栈帧                 │
├─────────────────────────────────┤
│  Java方法栈帧                   │
├─────────────────────────────────┤
│  Native方法栈帧                 │
└─────────────────────────────────┘
```

## 总结

**本地方法的特点：**
1. 用 `native` 关键字标识
2. 没有方法体（方法体在 C/C++ 中实现）
3. 通过 JNI 与 Java 代码交互
4. 主要用于系统调用、性能优化、硬件访问

**常见场景：**
- 操作系统交互：文件 I/O、网络通信、线程管理
- 底层操作：内存管理、并发控制（CAS）
- 性能关键代码：数组拷贝、数学运算
- 第三方库集成：图形库、加密库、数据库驱动

所以当你调用 `Thread.sleep()`、`System.arraycopy()` 这些方法时，实际上就是在使用本地方法，它们最终会在本地方法栈中执行对应的 C/C++ 代码！
