### 描述符

描述符（Descriptor）是 JVM 用来描述字段类型和方法签名的一种特殊字符串格式。如图所示：

【为什么需要描述符？】
✓ JVM 是跨语言的,需要统一的类型表示方法
✓ 字节码中没有变量名,只能通过描述符识别类型
✓ 方法重载依赖描述符区分(参数类型不同)
✓ 类型检查和验证的基础
```

**简单总结**：
- 描述符就是 JVM 的"类型语言"
- 把 Java 类型转换成紧凑的字符串表示
- 字节码中用它来精确描述字段和方法的类型信息

### **关键说明：**

1. **字面量**：代码中直接写死的值，如字符串、数字等
   - 字符串字面量 ：运行时常量池中存储的是**引用**（指针）
   - 数值常量：运行时常量池中**直接存储值**
2. **符号引用**：在编译时还不知道实际内存地址，用符号表示
3. **常量类型**：JVM 定义的 14 种常量类型标签，**直接存储字符串值**
4. **运行时特性**：类加载时从 Class 文件的常量池转化而来，运行期可动态扩展（如 String.intern()）

### 运行时常量存储的内理解

1. **基本类型常量**：直接存值，不需要引用
   - `CONSTANT_Integer`、`CONSTANT_Long`、`CONSTANT_Float`、`CONSTANT_Double`

2. **字符串常量**：存引用，指向堆
   - `CONSTANT_String` → 堆中的 String 对象

3. **符号引用**：存符号信息，解析后才变成直接引用
   - `CONSTANT_Class`、`CONSTANT_Fieldref`、`CONSTANT_Methodref`
   - 未解析时：只是名字（字符串）
   - 解析后：指向元空间中的实际元数据

4. **UTF-8 字符串**：直接存 UTF-8 字节
   - `CONSTANT_Utf8`：JVM 内部字符串表示，不是 Java String 对象

│  │  String s1 = "Hello";    // 字面量                       │  │
│  │  String s2 = "Hello";    // 相同字面量                   │  │

│  │     ① JVM 检查字符串常量池(堆中)是否存在 "Hello"        │  │

│  │                                                          │  │

│  │     ③ s1 == s2  // true (指向同一对象)                 │  │
│  │                                                          │  │
│  │  4. 执行 String s3 = new String("Hello"):              │  │
│  │     ① 在堆的普通区域创建新的 String 对象                │  │
│  │     ② s3 引用指向这个新对象                             │  │
│  │     ③ s1 == s3  // false (不同对象)                    │  │
│  │     ④ s1.equals(s3)  // true (内容相同)                │  │
│  └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  String.intern() 方法的作用                                     │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  String s4 = new String("World");                        │  │
│  │  String s5 = s4.intern();  // 尝试放入字符串常量池       │  │
│  │                                                          │  │
│  │  过程:                                                   │  │
│  │  • 检查字符串常量池是否已有 "World"                     │  │
│  │  • 如果没有: 将该字符串加入常量池,返回常量池引用        │  │
│  │  • 如果有: 直接返回常量池中已存在的引用                 │  │
│  └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘

【关键点总结】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✓ 运行时常量池存储的是"引用",真正的 String 对象在堆中
✓ 字符串字面量首次使用时,会在字符串常量池创建对象
✓ JDK 6: 字符串常量池在方法区(永久代)
✓ JDK 7+: 字符串常量池移到堆中(更大空间,避免永久代溢出)
✓ 运行时常量池和字符串常量池是协同工作的,不是调用关系
```
