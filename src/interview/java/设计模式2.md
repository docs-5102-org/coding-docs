# 工厂模式详解与对比

让我用一个贴近生活的例子来说明这三种工厂模式的区别。

---

## 场景设定：电子产品生产

假设我们要生产电子产品，包括**手机**和**笔记本电脑**两类产品，有**华为**和**小米**两个品牌。

---

## 1. 简单工厂模式

**特点**：一个工厂类，根据参数创建不同的产品（同一等级结构）

**问题**：如果要新增产品类型（比如增加平板电脑），必须修改工厂类代码，违反开闭原则

### 代码示例

```java
// 产品接口
interface Phone {
    void call();
}

// 具体产品
class HuaweiPhone implements Phone {
    @Override
    public void call() {
        System.out.println("使用华为手机打电话");
    }
}

class XiaomiPhone implements Phone {
    @Override
    public void call() {
        System.out.println("使用小米手机打电话");
    }
}

// 简单工厂 - 只能生产手机这一等级的产品
class SimplePhoneFactory {
    public static Phone createPhone(String brand) {
        switch (brand) {
            case "Huawei":
                return new HuaweiPhone();
            case "Xiaomi":
                return new XiaomiPhone();
            default:
                throw new IllegalArgumentException("不支持的品牌: " + brand);
        }
    }
}

// 使用
public class SimpleFactoryDemo {
    public static void main(String[] args) {
        Phone huaweiPhone = SimplePhoneFactory.createPhone("Huawei");
        huaweiPhone.call();
        
        Phone xiaomiPhone = SimplePhoneFactory.createPhone("Xiaomi");
        xiaomiPhone.call();
        
        // 如果要增加 OppoPhone，必须修改 SimplePhoneFactory 类
        // 违反了开闭原则（对扩展开放，对修改关闭）
    }
}
```

**优点**：实现简单，使用方便  
**缺点**：增加新产品需要修改工厂类，不符合开闭原则

---

## 2. 工厂方法模式

**特点**：每个品牌一个工厂类，生产该品牌的固定产品

**优势**：增加新品牌（新工厂）不需要修改原有代码，符合开闭原则

### 代码示例

```java
// 产品接口
interface Phone {
    void call();
}

// 具体产品
class HuaweiPhone implements Phone {
    @Override
    public void call() {
        System.out.println("使用华为手机打电话");
    }
}

class XiaomiPhone implements Phone {
    @Override
    public void call() {
        System.out.println("使用小米手机打电话");
    }
}

class OppoPhone implements Phone {
    @Override
    public void call() {
        System.out.println("使用OPPO手机打电话");
    }
}

// 抽象工厂
interface PhoneFactory {
    Phone createPhone();
}

// 具体工厂 - 每个品牌一个工厂
class HuaweiFactory implements PhoneFactory {
    @Override
    public Phone createPhone() {
        return new HuaweiPhone();
    }
}

class XiaomiFactory implements PhoneFactory {
    @Override
    public Phone createPhone() {
        return new XiaomiPhone();
    }
}

// 新增OPPO品牌，只需增加工厂类，无需修改原有代码
class OppoFactory implements PhoneFactory {
    @Override
    public Phone createPhone() {
        return new OppoPhone();
    }
}

// 使用
public class FactoryMethodDemo {
    public static void main(String[] args) {
        PhoneFactory huaweiFactory = new HuaweiFactory();
        Phone huaweiPhone = huaweiFactory.createPhone();
        huaweiPhone.call();
        
        PhoneFactory xiaomiFactory = new XiaomiFactory();
        Phone xiaomiPhone = xiaomiFactory.createPhone();
        xiaomiPhone.call();
        
        // 新增品牌很容易
        PhoneFactory oppoFactory = new OppoFactory();
        Phone oppoPhone = oppoFactory.createPhone();
        oppoPhone.call();
    }
}
```

**优点**：符合开闭原则，易于扩展新品牌  
**缺点**：每个品牌只能生产一种产品（如只能生产手机）

---

## 3. 抽象工厂模式

**特点**：每个品牌一个工厂，可以生产该品牌的一系列产品（产品族）

**优势**：可以保证同一品牌的产品协同工作  
**问题**：增加新产品类型（如增加平板电脑）需要修改所有工厂接口和实现类

### 代码示例

```java
// 产品接口 - 手机
interface Phone {
    void call();
}

// 产品接口 - 笔记本电脑
interface Laptop {
    void work();
}

// 华为产品族
class HuaweiPhone implements Phone {
    @Override
    public void call() {
        System.out.println("使用华为手机打电话");
    }
}

class HuaweiLaptop implements Laptop {
    @Override
    public void work() {
        System.out.println("使用华为笔记本工作");
    }
}

// 小米产品族
class XiaomiPhone implements Phone {
    @Override
    public void call() {
        System.out.println("使用小米手机打电话");
    }
}

class XiaomiLaptop implements Laptop {
    @Override
    public void work() {
        System.out.println("使用小米笔记本工作");
    }
}

// 抽象工厂 - 可以生产多种产品
interface ElectronicsFactory {
    Phone createPhone();
    Laptop createLaptop();
}

// 具体工厂 - 华为工厂生产华为全系列产品
class HuaweiFactory implements ElectronicsFactory {
    @Override
    public Phone createPhone() {
        return new HuaweiPhone();
    }
    
    @Override
    public Laptop createLaptop() {
        return new HuaweiLaptop();
    }
}

// 具体工厂 - 小米工厂生产小米全系列产品
class XiaomiFactory implements ElectronicsFactory {
    @Override
    public Phone createPhone() {
        return new XiaomiPhone();
    }
    
    @Override
    public Laptop createLaptop() {
        return new XiaomiLaptop();
    }
}

// 使用
public class AbstractFactoryDemo {
    public static void main(String[] args) {
        // 使用华为产品族
        ElectronicsFactory huaweiFactory = new HuaweiFactory();
        Phone huaweiPhone = huaweiFactory.createPhone();
        Laptop huaweiLaptop = huaweiFactory.createLaptop();
        huaweiPhone.call();
        huaweiLaptop.work();
        
        System.out.println("---");
        
        // 使用小米产品族
        ElectronicsFactory xiaomiFactory = new XiaomiFactory();
        Phone xiaomiPhone = xiaomiFactory.createPhone();
        Laptop xiaomiLaptop = xiaomiFactory.createLaptop();
        xiaomiPhone.call();
        xiaomiLaptop.work();
        
        // 优点：新增品牌（OPPO）很容易，只需新增一个工厂类
        // 缺点：如果要增加新产品（如平板Tablet），需要修改所有工厂接口和实现类
    }
}
```

**增加新产品族的示例**（容易）：

```java
// 新增OPPO产品族 - 只需新增类，无需修改原有代码
class OppoPhone implements Phone {
    @Override
    public void call() {
        System.out.println("使用OPPO手机打电话");
    }
}

class OppoLaptop implements Laptop {
    @Override
    public void work() {
        System.out.println("使用OPPO笔记本工作");
    }
}

class OppoFactory implements ElectronicsFactory {
    @Override
    public Phone createPhone() {
        return new OppoPhone();
    }
    
    @Override
    public Laptop createLaptop() {
        return new OppoLaptop();
    }
}
```

**增加新产品等级的示例**（困难）：

```java
// 如果要增加平板电脑这个新产品等级
// 需要修改抽象工厂接口
interface ElectronicsFactory {
    Phone createPhone();
    Laptop createLaptop();
    Tablet createTablet();  // 新增方法
}

// 所有具体工厂都要实现新方法
class HuaweiFactory implements ElectronicsFactory {
    @Override
    public Phone createPhone() {
        return new HuaweiPhone();
    }
    
    @Override
    public Laptop createLaptop() {
        return new HuaweiLaptop();
    }
    
    @Override
    public Tablet createTablet() {  // 必须实现
        return new HuaweiTablet();
    }
}

// 小米、OPPO等所有工厂类都要修改
// 这就是抽象工厂的缺点
```

## 三种工厂模式对比表

| 维度 | 简单工厂 | 工厂方法 | 抽象工厂 |
|------|---------|---------|---------|
| **定义** | 一个工厂类根据参数创建产品 | 每个产品一个工厂类 | 每个产品族一个工厂类 |
| **产品数量** | 生产同一等级的任意产品 | 生产同一等级的固定产品 | 生产不同等级的一系列产品 |
| **工厂数量** | 1个工厂 | 多个工厂（每个产品一个） | 多个工厂（每个产品族一个） |
| **增加新产品** | ❌ 需修改工厂类 | ✅ 新增工厂类即可 | ❌ 需修改所有工厂 |
| **增加新品牌** | ❌ 需修改工厂类 | ✅ 新增工厂类即可 | ✅ 新增工厂类即可 |
| **符合开闭原则** | ❌ 否 | ✅ 是 | ⚠️ 部分（仅对产品族） |

## 形象比喻

### 简单工厂
> 一家手机专卖店，只卖手机，可以卖华为、小米、OPPO等各种品牌手机。  
> 如果想卖笔记本，需要改造店铺。

### 工厂方法
> 华为专卖店（只卖华为手机）、小米专卖店（只卖小米手机）。  
> 想增加OPPO手机？开一家OPPO专卖店就行。

### 抽象工厂
> 华为旗舰店（卖华为手机、华为笔记本、华为平板等全系列产品）、小米旗舰店（卖小米全系列产品）。  
> 想增加OPPO品牌？开一家OPPO旗舰店。  
> 想所有店都增加耳机？每家店都要装修改造。

---

## 核心区别总结

**产品等级结构**：产品的继承关系（如手机、笔记本都是电子产品）

**产品族**：同一品牌的不同产品（如华为手机、华为笔记本）

- **简单工厂**：只关注一个产品等级（如只生产手机），用参数区分品牌
- **工厂方法**：每个品牌一个工厂，生产该品牌的某一产品
- **抽象工厂**：每个品牌一个工厂，生产该品牌的一系列产品

**扩展性对比**：

```
简单工厂：增加产品 ❌  增加品牌 ❌
工厂方法：增加产品 ❌  增加品牌 ✅
抽象工厂：增加产品 ❌  增加品牌 ✅  且可生产多种产品
```

## 实际应用场景

### 简单工厂
```java

NumberFormat.getInstance();  // 根据地区返回不同的NumberFormat实例
```

### 工厂方法
```java
// JDBC驱动加载

// 不同数据库有不同的Driver实现

// 日志框架

// 不同日志框架有不同的LoggerFactory实现
```

### 抽象工厂
```java
// Java AWT/Swing
// 不同操作系统有不同的UI组件工厂
// Windows工厂生产：WindowsButton、WindowsTextField、WindowsScrollBar
// Mac工厂生产：MacButton、MacTextField、MacScrollBar

// Spring中的BeanFactory也类似抽象工厂
// 可以创建多种类型的Bean
```

---

## 选择建议

1. **产品种类少且不常变化** → 使用简单工厂
2. **需要灵活增加品牌** → 使用工厂方法
3. **有产品族概念，需要保证产品一致性** → 使用抽象工厂

记住：**没有最好的模式，只有最合适的场景**。

## 完整对比示例代码

让我用一个完整的例子把三种模式串起来：

```java
// ============ 场景：生产交通工具 ============

// 产品接口
interface Vehicle {
    void run();
}

// ============ 简单工厂示例 ============
class Car implements Vehicle {
    @Override
    public void run() {
        System.out.println("汽车在公路上行驶");
    }
}

class Train implements Vehicle {
    @Override
    public void run() {
        System.out.println("火车在铁轨上行驶");
    }
}

class SimpleVehicleFactory {
    public static Vehicle createVehicle(String type) {
        if ("car".equals(type)) {
            return new Car();
        } else if ("train".equals(type)) {
            return new Train();
        }
        throw new IllegalArgumentException("未知类型");
    }
}

// ============ 工厂方法示例 ============
interface VehicleFactory {
    Vehicle createVehicle();
}

class CarFactory implements VehicleFactory {
    @Override
    public Vehicle createVehicle() {
        return new Car();
    }
}

class TrainFactory implements VehicleFactory {
    @Override
    public Vehicle createVehicle() {
        return new Train();
    }
}

// ============ 抽象工厂示例 ============
// 增加发动机产品
interface Engine {
    void start();
}

class CarEngine implements Engine {
    @Override
    public void start() {
        System.out.println("汽车发动机启动");
    }
}

class TrainEngine implements Engine {
    @Override
    public void start() {
        System.out.println("火车发动机启动");
    }
}

// 抽象工厂可以生产一系列产品
interface TransportFactory {
    Vehicle createVehicle();
    Engine createEngine();
}

class CarTransportFactory implements TransportFactory {
    @Override
    public Vehicle createVehicle() {
        return new Car();
    }
    
    @Override
    public Engine createEngine() {
        return new CarEngine();
    }
}

class TrainTransportFactory implements TransportFactory {
    @Override
    public Vehicle createVehicle() {
        return new Train();
    }
    
    @Override
    public Engine createEngine() {
        return new TrainEngine();
    }
}
```

通过这个例子可以清楚地看到：

1. **简单工厂**：一个工厂生产所有类型的交通工具
2. **工厂方法**：汽车工厂只生产汽车，火车工厂只生产火车
3. **抽象工厂**：汽车工厂生产汽车+汽车发动机，火车工厂生产火车+火车发动机（保证产品族一致性）

希望这个详细的对比能帮助你理解三种工厂模式的区别！
