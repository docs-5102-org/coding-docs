# 反射与对象拷贝

## 一、Java反射机制

### 1.1 什么是反射？

**反射（Reflection）** 是Java语言的一种重要特性，它允许程序在运行时动态地获取类的信息并操作类的属性和方法。

具体来说，反射机制可以实现：
- 在运行时判断任意一个对象所属的类
- 在运行时构造任意一个类的对象
- 在运行时判断任意一个类所具有的成员变量和方法
- 在运行时调用任意一个对象的方法和属性
- 生成动态代理

**核心概念**：这种动态获取信息以及动态调用对象方法的功能称为Java语言的反射机制。

### 1.2 获取反射的三种方法

Java中获取Class对象有三种常用方式：

#### 方式一：通过对象实例获取
```java
Person person = new Person();
Class<?> clazz = person.getClass();
```

#### 方式二：通过类的全限定名获取
```java
Class<?> clazz = Class.forName("com.example.Person");
```

#### 方式三：通过类名获取
```java
Class<?> clazz = Person.class;
```

### 1.3 反射的常用API

```java
// 获取类的所有公共方法
Method[] methods = clazz.getMethods();

// 获取类的所有声明方法（包括私有）
Method[] declaredMethods = clazz.getDeclaredMethods();

// 获取所有公共字段
Field[] fields = clazz.getFields();

// 获取所有声明字段
Field[] declaredFields = clazz.getDeclaredFields();

// 获取所有构造器
Constructor<?>[] constructors = clazz.getConstructors();

// 创建实例
Object instance = clazz.newInstance();
```

### 1.4 反射的应用场景

- **框架开发**：Spring IoC容器、MyBatis等框架大量使用反射
- **动态代理**：AOP实现的基础
- **注解处理**：运行时解析注解
- **序列化/反序列化**：通用的对象持久化方案
- **IDE工具**：代码提示、自动补全等功能

## 二、Java序列化

### 2.1 什么是序列化？

**Java序列化**是指将对象的状态信息转换为可以存储或传输的形式（字节序列）的过程。通过序列化，可以把对象的状态保存到文件、数据库中，或者通过网络传输到其他地方。

**反序列化**则是将字节序列恢复为Java对象的过程。

### 2.2 何时需要使用序列化？

以下场景需要使用Java序列化：

1. **持久化对象状态**  
   将内存中的对象状态保存到文件或数据库中，以便后续读取

2. **网络传输**  
   使用Socket在网络上传输对象数据

3. **远程方法调用（RMI）**  
   在分布式系统中传输对象参数和返回值

4. **进程间通信**  
   不同JVM进程之间传递对象数据

### 2.3 如何实现序列化？

```java
import java.io.Serializable;

public class Person implements Serializable {
    private static final long serialVersionUID = 1L;
    
    private String name;
    private int age;
    
    // 构造方法、getter、setter省略
}
```

**序列化操作**：
```java
// 序列化
ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("person.ser"));
oos.writeObject(person);
oos.close();

// 反序列化
ObjectInputStream ois = new ObjectInputStream(new FileInputStream("person.ser"));
Person person = (Person) ois.readObject();
ois.close();
```

**注意事项**：
- 必须实现`Serializable`接口（标记接口）
- 建议显式声明`serialVersionUID`以确保版本兼容性
- `transient`关键字修饰的字段不会被序列化
- 静态变量不会被序列化

## 三、对象拷贝

### 4.1 为什么需要克隆？

在实际开发中，我们经常需要复制对象。使用`new`关键字创建的对象，其属性都是初始值；而通过克隆得到的对象，可以保留原对象修改后的状态。

**使用场景**：
- 需要保存对象的当前状态作为备份
- 需要在不影响原对象的情况下修改对象
- 创建大量相似对象时提高性能

### 4.2 如何实现对象克隆？

#### 方式一：实现Cloneable接口

```java
public class Person implements Cloneable {
    private String name;
    private int age;
    
    @Override
    protected Object clone() throws CloneNotSupportedException {
        return super.clone();
    }
}

// 使用
Person p1 = new Person("张三", 25);
Person p2 = (Person) p1.clone();
```

#### 方式二：通过序列化实现深拷贝

```java
public class Person implements Serializable {
    private static final long serialVersionUID = 1L;
    private String name;
    private Address address;
    
    public Person deepClone() {
        try {
            ByteArrayOutputStream bos = new ByteArrayOutputStream();
            ObjectOutputStream oos = new ObjectOutputStream(bos);
            oos.writeObject(this);
            
            ByteArrayInputStream bis = new ByteArrayInputStream(bos.toByteArray());
            ObjectInputStream ois = new ObjectInputStream(bis);
            return (Person) ois.readObject();
        } catch (Exception e) {
            e.printStackTrace();
            return null;
        }
    }
}
```

### 4.3 浅拷贝与深拷贝

#### 浅拷贝（Shallow Copy）

**定义**：复制对象时，只复制对象本身和其中的基本数据类型字段，引用类型字段仍然指向原对象中的引用。

**特点**：
- 基本类型字段：拷贝值
- 引用类型字段：拷贝引用地址
- 修改引用类型字段会影响原对象

```java
public class Person implements Cloneable {
    private String name;
    private Address address;  // 引用类型
    
    @Override
    protected Object clone() throws CloneNotSupportedException {
        return super.clone();  // 浅拷贝
    }
}
```

#### 深拷贝（Deep Copy）

**定义**：复制对象时，不仅复制对象本身，还递归复制对象中包含的所有引用类型对象。

**特点**：
- 创建完全独立的副本
- 修改任何字段都不会影响原对象
- 实现较复杂，性能开销较大

```java
public class Person implements Cloneable {
    private String name;
    private Address address;
    
    @Override
    protected Object clone() throws CloneNotSupportedException {
        Person cloned = (Person) super.clone();
        // 深拷贝引用类型字段
        cloned.address = (Address) address.clone();
        return cloned;
    }
}
```

#### 对比总结

| 特性 | 浅拷贝 | 深拷贝 |
|------|--------|--------|
| 基本类型 | 拷贝值 | 拷贝值 |
| 引用类型 | 拷贝引用 | 拷贝对象 |
| 独立性 | 部分独立 | 完全独立 |
| 实现难度 | 简单 | 较复杂 |
| 性能 | 高 | 相对较低 |

### 4.4 实战示例

**示例参考**：[Java深拷贝与浅拷贝详解](https://blog.csdn.net/qq_37113604/article/details/81168224)

```java
// 浅拷贝示例
class Address {
    String city;
    
    public Address(String city) {
        this.city = city;
    }
}

class Person implements Cloneable {
    String name;
    Address address;
    
    public Person(String name, Address address) {
        this.name = name;
        this.address = address;
    }
    
    @Override
    protected Object clone() throws CloneNotSupportedException {
        return super.clone();
    }
}

// 测试
Person p1 = new Person("张三", new Address("北京"));
Person p2 = (Person) p1.clone();
p2.address.city = "上海";

System.out.println(p1.address.city);  // 输出：上海（浅拷贝，引用相同）
```
