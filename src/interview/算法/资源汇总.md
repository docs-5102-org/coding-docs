# 🧠 算法学习资源汇总

> 本文汇总了系统学习数据结构与算法的优质资源，涵盖书籍、在线课程、刷题平台、开源项目及社区，适合从初学者到进阶开发者的不同阶段。

# 算法学习资源汇总

## 📚 书籍 · 入门

- **《算法图解》** — 图文并茂，零基础友好，Python 示例。涵盖排序、递归、图算法、动态规划基础
- **《大话数据结构》** — 中文写作，生动幽默，适合国内读者入门。涵盖链表、栈、队列、树、图
- **《学习 JavaScript 数据结构与算法》** — 前端友好，JS 示例，覆盖常见数据结构。涵盖数组、链表、树、图、排序

## 📚 书籍 · 进阶

- **《算法》第4版** — Java 实现，配套网站资源丰富。涵盖排序、图、字符串、动态规划
- **《数据结构与算法分析》** — 理论严谨，有 C++/Java/Python 多语言版本。涵盖复杂度分析、堆、AVL 树、散列
- **《算法导论》（CLRS）** — 算法圣经，数学推导深入，适合深度研究。全覆盖排序、图、DP、NP 完全性

## 📚 书籍 · 面试

- **《剑指 Offer》** — 国内面试经典，BAT 高频题目。涵盖数组、链表、树、回溯、DP
- **《程序员代码面试指南》** — 题量大，解析详细，进阶首选。大量算法题，系统分类
- **Cracking the Coding Interview** — 外企面试必读，189 道高频题。涵盖数据结构 + 算法 + 系统设计

## 🎬 在线课程

- **MIT 6.006** — 麻省理工公开课，含完整讲义与习题，免费。涵盖排序、图、DP、最短路径
  https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/

- **Stanford CS161** — 斯坦福算法课，偏重理论分析与复杂度证明，免费。涵盖分治、贪心、图算法、随机算法
  https://web.stanford.edu/class/cs161/

- **极客时间·数据结构与算法之美** — 王争（前 Google）主讲，结合工程场景，中文，付费。涵盖数组、链表、树、图、DP、排序
  https://time.geekbang.org/column/intro/126

- **B站·左程云算法课** — 国内最受欢迎算法 UP 主之一，免费内容丰富。全覆盖数据结构与算法
  https://space.bilibili.com/8888480

- **Coursera Algorithms Specialization** — Tim Roughgarden 主讲，4 门课系列，可申请助学金。涵盖分治、图、贪心、DP、NP
  https://www.coursera.org/specializations/algorithms

- **NeetCode.io** — 基于 LeetCode 150 题整理，配套 YouTube 视频。涵盖数组、滑窗、二分、DP、图
  https://neetcode.io/

- **LeetCode 探索** — 官方结构化学习路径，按专题卡片分类
  https://leetcode.cn/explore/

## 💻 刷题平台

- **LeetCode** — 题库最全，面试覆盖率最高，支持多语言。全算法覆盖，含周赛 & 竞赛
  https://leetcode.cn/

- **AcWing** — 算法竞赛导向，系统性强，中文。涵盖竞赛算法：DP、图论、数学
  https://www.acwing.com/

- **牛客网** — 模拟笔试，企业真题，适合校招
  https://www.nowcoder.com/

- **Codeforces** — 国际竞赛平台，题目质量极高，Rating 体系。涵盖数论、构造、图论
  https://codeforces.com/

- **洛谷** — 国内 OI 竞赛平台，题解丰富。OI 竞赛全算法
  https://www.luogu.com.cn/

- **HackerRank** — 外企招聘常用，按域分类清晰。涵盖算法、数据结构、SQL、AI
  https://www.hackerrank.com/
