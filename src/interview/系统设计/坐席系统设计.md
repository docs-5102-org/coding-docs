


# 基于项目经验的面试题（20道）

根据你的项目职责，我为你准备了涵盖各技术领域的面试题：

## 一、智能坐席与通话控制（4题）

1. **请详细描述智能坐席系统中"技能路由"的实现原理，如何在高并发场景下快速匹配合适的坐席？涉及哪些数据结构和算法？**

2. **坐席状态管理中，如何保证状态一致性？当网络抖动或服务重启时，如何恢复坐席的正确状态？**

3. **通话控制模块的状态机如何设计？请画出主要状态及其转换条件，并说明如何处理异常状态（如通话中突然断网）。**

4. **在高并发场景下，多个呼叫同时进来，如何实现公平且高效的坐席分配？如何避免"惊群效应"？**

## 二、微服务架构与治理（4题）

5. **你们的微服务注册中心选用了什么方案？请对比 Nacos、Eureka、Consul 的优劣，并说明在什么场景下会发生服务注册延迟问题。**

6. **熔断和限流的区别是什么？请结合实际案例说明你们如何配置 Sentinel/Hystrix 的熔断阈值，以及如何监控熔断效果。**

7. **配置中心如何实现配置的热更新？如果某个服务实例没有及时拉取到最新配置，会带来什么问题？如何解决？**

8. **微服务间调用链路很长，如何快速定位某个请求的性能瓶颈？请说明链路追踪的实现原理（TraceId、SpanId 的传递机制）。**

## 三、SIP/VoIP 与通话技术（3题）

9. **请简述 SIP 协议的通话建立流程（INVITE、ACK、BYE 等消息），以及如何处理"振铃无应答"和"通话中断"的场景。**

10. **录音落盘时，如何保证录音文件的完整性和一致性？如果录音服务宕机，如何避免录音丢失？**

11. **语音中继对接时，如何处理多运营商、多线路的容灾切换？请说明你们的主备切换策略和健康检查机制。**

## 四、订单与支付系统（3题）

12. **订单系统如何设计才能支持复杂的订单生命周期（待支付、已支付、已取消、已退款等）？状态机如何设计？如何防止状态回退？**

13. **支付回调接口如何实现幂等性？请说明你们采用的幂等方案（如唯一流水号、Redis分布式锁、数据库唯一索引等）及其优缺点。**

14. **在高并发支付场景下，如何进行风控校验？请说明风控规则的设计思路（如频率限制、异常检测、黑名单校验等）。**

## 五、优惠券与防超发（2题）

15. **优惠券核销时，如何用 Redis 实现防超发？请详细说明你们的技术方案（如 Lua 脚本、分布式锁、预扣减等），以及如何处理缓存与数据库的一致性。**

16. **券模板设计时，如何支持多种优惠类型（满减券、折扣券、兑换券）？如何设计数据库表结构以支持灵活的券规则配置？**

## 六、Redis 高并发优化（2题）

17. **Redis Cluster 模式下，如何处理热点 Key 的问题？请说明你们采用的优化方案（如本地缓存、数据分片、读写分离等）。**

18. **库存并发控制场景下，如何用 Redis 实现扣减操作？请对比 Lua 脚本、分布式锁、Redis事务的优劣，并说明你们的选择理由。**

## 七、性能优化与稳定性（2题）

19. **请列举你在项目中遇到的 3 个典型慢 SQL 案例，并说明如何定位问题（explain、慢日志）以及如何优化（索引、分库分表、查询改写等）。**

20. **队列削峰填谷的场景下，如何设计消息队列的消费策略？如果消息堆积严重，如何快速处理？如何保证消息不丢失、不重复消费？**

---

## 答题建议

针对这些问题，建议你：
- **结合实际项目经验**回答，说明具体场景和数据量级
- **突出问题解决思路**，而非只说技术选型
- **准备画图**说明架构设计（如状态机、调用链路、数据流向）
- **量化优化效果**（如 QPS 提升、响应时间降低、稳定性指标等）

祝面试顺利！
