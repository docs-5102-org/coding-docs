# 融合通信云平台相关面试题-Redis 优化（5题）

## 16. Redis Cluster 的架构是什么？集群规模和配置？

### Redis Cluster 核心架构

**分片机制（Hash Slot）**
```
Redis Cluster 采用虚拟槽分区：
- 总共 16384 个槽位（0-16383）
- 每个 key 通过 CRC16(key) % 16384 计算槽位
- 每个主节点负责一部分槽位
- 支持动态增删节点和槽位迁移
```

**架构组成**
```
典型的 3主3从架构：

Master-1 (0-5460)          Master-2 (5461-10922)       Master-3 (10923-16383)
    |                           |                            |
Slave-1                     Slave-2                      Slave-3

特点：
- 每个节点都知道其他节点的信息（Gossip 协议）
- 客户端可以连接任意节点
- 自动故障转移
```

### 实际项目配置示例

```yaml
# redis.conf 关键配置
cluster-enabled yes
cluster-config-file nodes-6379.conf
cluster-node-timeout 15000
cluster-require-full-coverage no  # 部分槽位失效时仍可用

# 主从配置
repl-diskless-sync yes
repl-backlog-size 256mb

# 内存配置
maxmemory 8gb
maxmemory-policy allkeys-lru

# 持久化配置
save 900 1
save 300 10
appendonly yes
appendfsync everysec
```

**集群规模配置**

```
小型电商项目：
- 3 主 3 从，每节点 8GB 内存
- QPS: 5万/秒
- 数据量: 50GB

中型项目：
- 6 主 6 从，每节点 16GB 内存
- QPS: 20万/秒
- 数据量: 200GB

大型项目：
- 12 主 12 从，每节点 32GB 内存
- QPS: 100万/秒
- 数据量: 1TB+
```

**客户端配置**

```java
@Configuration
public class RedisClusterConfig {
    
    @Bean
    public RedissonClient redissonClient() {
        Config config = new Config();
        config.useClusterServers()
            // 只需要配置 3 个主节点即可（甚至配置1个也行）
            .addNodeAddress(
                "redis://192.168.1.1:6379",  // Master-1
                "redis://192.168.1.2:6379",  // Master-2
                "redis://192.168.1.3:6379"   // Master-3
            )
            // 连接池配置
            .setMasterConnectionPoolSize(64)    // 主节点连接池
            .setSlaveConnectionPoolSize(64)     // 从节点连接池
            .setMasterConnectionMinimumIdleSize(10)
            .setSlaveConnectionMinimumIdleSize(10)
            
            // 重试配置
            .setRetryAttempts(3)                // 重试次数
            .setRetryInterval(1500)             // 重试间隔
            .setTimeout(3000)                   // 响应超时
            .setConnectTimeout(10000)           // 连接超时
            
            // 集群配置
            .setScanInterval(2000)              // 集群状态扫描间隔
            .setReadMode(ReadMode.SLAVE)        // 读从节点，写主节点
            .setSubscriptionMode(SubscriptionMode.MASTER);  // 订阅模式
        
        return Redisson.create(config);
    }
}
```

### 为什么不需要配置所有6个节点？
```
Redis Cluster 的自动发现机制：

1. 客户端连接任意一个节点
   ↓
2. 通过 CLUSTER NODES 命令获取完整集群拓扑
   ↓
3. 自动发现所有主从节点的地址和槽位分布
   ↓
4. 客户端内部维护完整的集群连接池
```

## 17. 热点数据治理：发现和解决热点 Key

### 如何发现热点 Key

**方案一：Redis 自带命令监控**
```bash

# 或使用 monitor（生产环境慎用，影响性能）
redis-cli monitor | awk '{print $4}' | sort | uniq -c | sort -rn | head -10
```

**方案二：客户端统计**
```java
@Aspect
@Component
public class RedisKeyMonitorAspect {
    
    private final ConcurrentHashMap<String, AtomicLong> keyAccessCount = new ConcurrentHashMap<>();
    private final ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(1);
    
    @PostConstruct
    public void init() {
        // 每分钟统计一次
        scheduler.scheduleAtFixedRate(() -> {
            List<Map.Entry<String, AtomicLong>> hotKeys = keyAccessCount.entrySet().stream()
                .sorted((a, b) -> Long.compare(b.getValue().get(), a.getValue().get()))
                .limit(10)
                .collect(Collectors.toList());
            
            log.info("热点 Key 统计: {}", hotKeys);
            
            // 发送告警
            hotKeys.forEach(entry -> {
                if (entry.getValue().get() > 10000) {
                    alertService.sendHotKeyAlert(entry.getKey(), entry.getValue().get());
                }
            });
            
            keyAccessCount.clear();
        }, 1, 1, TimeUnit.MINUTES);
    }
    
    @Around("execution(* com.example.cache..*(..))")
    public Object monitor(ProceedingJoinPoint pjp) throws Throwable {
        Object[] args = pjp.getArgs();
        if (args.length > 0 && args[0] instanceof String) {
            String key = (String) args[0];
            keyAccessCount.computeIfAbsent(key, k -> new AtomicLong()).incrementAndGet();
        }
        return pjp.proceed();
    }
}
```

```java
public class HotKeyShardingService {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    private static final int SHARD_COUNT = 10; // 分10个副本
    
    public void setHotKey(String key, Object value) {
        // 写入所有分片
        for (int i = 0; i < SHARD_COUNT; i++) {
            String shardKey = key + "#" + i;
            redisTemplate.opsForValue().set(shardKey, value, 1, TimeUnit.HOURS);
        }
    }
    
    public Object getHotKey(String key) {
        // 随机读取一个分片，分散压力
        int shardIndex = ThreadLocalRandom.current().nextInt(SHARD_COUNT);
        String shardKey = key + "#" + shardIndex;
        return redisTemplate.opsForValue().get(shardKey);
    }
}
```

## 18. 分布式锁方案：Redisson vs 自实现

### Redisson 分布式锁（推荐）

**基础使用**
```java
@Service
public class RedissonLockService {
    
    @Autowired
    private RedissonClient redissonClient;
    
    public void processOrder(String orderId) {
        String lockKey = "order:lock:" + orderId;
        RLock lock = redissonClient.getLock(lockKey);
        
        try {
            // 尝试加锁，最多等待10秒，锁自动释放时间30秒
            boolean acquired = lock.tryLock(10, 30, TimeUnit.SECONDS);
            
            if (acquired) {
                // 执行业务逻辑
                processOrderLogic(orderId);
            } else {
                throw new BusinessException("获取锁失败，请稍后重试");
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new BusinessException("锁等待被中断");
        } finally {
            // 释放锁（只有当前线程持有锁时才会释放）
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
}
```

**看门狗机制（自动续期）**
```java
public void processLongTask(String taskId) {

        // 执行长时间任务
        longRunningTask(taskId);

        lock.unlock();
    }
}
```

### 自实现分布式锁

**基于 SET NX EX 的实现**
```java
@Component
public class CustomRedisLock {
    
    @Autowired
    private StringRedisTemplate redisTemplate;
    
    private static final String LOCK_PREFIX = "lock:";
    private static final ThreadLocal<String> LOCK_ID = new ThreadLocal<>();
    
    public boolean tryLock(String key, long expireTime, TimeUnit unit) {
        String lockKey = LOCK_PREFIX + key;
        String lockValue = UUID.randomUUID().toString();
        
        Boolean success = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, lockValue, expireTime, unit);
        
        if (Boolean.TRUE.equals(success)) {
            LOCK_ID.set(lockValue);
            return true;
        }
        return false;
    }
    
    public void unlock(String key) {
        String lockKey = LOCK_PREFIX + key;
        String lockValue = LOCK_ID.get();
        
        // 使用 Lua 脚本保证原子性：先判断再删除
        String script = 
            "if redis.call('get', KEYS[1]) == ARGV[1] then " +
            "    return redis.call('del', KEYS[1]) " +
            "else " +
            "    return 0 " +
            "end";
        
        redisTemplate.execute(
            new DefaultRedisScript<>(script, Long.class),
            Collections.singletonList(lockKey),
            lockValue
        );
        
        LOCK_ID.remove();
    }
}
```

**自实现可重入锁**
```java
@Component
public class ReentrantRedisLock {
    
    @Autowired
    private StringRedisTemplate redisTemplate;
    
    private static final ThreadLocal<Map<String, Integer>> LOCK_COUNT = 
        ThreadLocal.withInitial(HashMap::new);
    
    public boolean lock(String key, long expireTime) {
        String lockKey = "reentrant:lock:" + key;
        String threadId = Thread.currentThread().getId() + "";
        
        Map<String, Integer> countMap = LOCK_COUNT.get();
        Integer count = countMap.getOrDefault(lockKey, 0);
        
        if (count > 0) {
            // 可重入：同一线程再次获取锁
            countMap.put(lockKey, count + 1);
            return true;
        }
        
        // Lua 脚本实现可重入逻辑
        String script = 
            "if redis.call('exists', KEYS[1]) == 0 then " +
            "    redis.call('hset', KEYS[1], ARGV[1], 1) " +
            "    redis.call('expire', KEYS[1], ARGV[2]) " +
            "    return 1 " +
            "elseif redis.call('hexists', KEYS[1], ARGV[1]) == 1 then " +
            "    redis.call('hincrby', KEYS[1], ARGV[1], 1) " +
            "    redis.call('expire', KEYS[1], ARGV[2]) " +
            "    return 1 " +
            "else " +
            "    return 0 " +
            "end";
        
        Long result = redisTemplate.execute(
            new DefaultRedisScript<>(script, Long.class),
            Collections.singletonList(lockKey),
            threadId,
            String.valueOf(expireTime)
        );
        
        if (result != null && result == 1) {
            countMap.put(lockKey, 1);
            return true;
        }
        return false;
    }
    
    public void unlock(String key) {
        String lockKey = "reentrant:lock:" + key;
        String threadId = Thread.currentThread().getId() + "";
        
        Map<String, Integer> countMap = LOCK_COUNT.get();
        Integer count = countMap.get(lockKey);
        
        if (count == null || count == 0) {
            return;
        }
        
        if (count > 1) {
            countMap.put(lockKey, count - 1);
            return;
        }
        
        // Lua 脚本释放锁
        String script = 
            "if redis.call('hexists', KEYS[1], ARGV[1]) == 0 then " +
            "    return nil " +
            "else " +
            "    local counter = redis.call('hincrby', KEYS[1], ARGV[1], -1) " +
            "    if counter > 0 then " +
            "        return 0 " +
            "    else " +
            "        redis.call('del', KEYS[1]) " +
            "        return 1 " +
            "    end " +
            "end";
        
        redisTemplate.execute(
            new DefaultRedisScript<>(script, Long.class),
            Collections.singletonList(lockKey),
            threadId
        );
        
        countMap.remove(lockKey);
    }
}
```

## 19. 二级缓存方案设计

### 架构设计

```
请求流程：
┌─────────┐    ┌──────────────┐    ┌─────────┐    ┌──────────┐
│ 应用层  │ -> │ 本地缓存(L1) │ -> │ Redis(L2)│ -> │ 数据库   │
│         │ <- │  Caffeine    │ <- │          │ <- │          │
└─────────┘    └──────────────┘    └─────────┘    └──────────┘
                     ↑                    ↑
                     └────────────────────┘
                       缓存一致性保证
```

### 完整实现方案

```java
@Configuration
public class TwoLevelCacheConfig {
    
    @Bean
    public Cache<String, Object> localCache() {
        return Caffeine.newBuilder()
            .maximumSize(10000)
            .expireAfterWrite(5, TimeUnit.MINUTES)
            .expireAfterAccess(3, TimeUnit.MINUTES)
            .recordStats()
            .removalListener((key, value, cause) -> {
                log.info("本地缓存移除: key={}, cause={}", key, cause);
            })
            .build();
    }
}

@Service
public class TwoLevelCacheService {
    
    @Autowired
    private Cache<String, Object> localCache;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Autowired
    private RedisMessageListenerContainer messageListenerContainer;
    
    private static final String CACHE_TOPIC = "cache:invalidate";
    
    @PostConstruct
    public void init() {
        // 订阅缓存失效消息
        messageListenerContainer.addMessageListener(
            (message, pattern) -> {
                String key = new String(message.getBody());
                localCache.invalidate(key);
                log.info("收到缓存失效通知: {}", key);
            },
            new PatternTopic(CACHE_TOPIC)
        );
    }
    
    public Object get(String key) {
        // 1. 先查本地缓存
        Object value = localCache.getIfPresent(key);
        if (value != null) {
            log.debug("命中本地缓存: {}", key);
            return value;
        }
        
        // 2. 查 Redis
        value = redisTemplate.opsForValue().get(key);
        if (value != null) {
            log.debug("命中 Redis 缓存: {}", key);
            localCache.put(key, value);
            return value;
        }
        
        // 3. 查数据库
        value = getFromDatabase(key);
        if (value != null) {
            // 写入两级缓存
            set(key, value);
        }
        
        return value;
    }
    
    public void set(String key, Object value) {
        // 先写 Redis
        redisTemplate.opsForValue().set(key, value, 1, TimeUnit.HOURS);
        
        // 再写本地缓存
        localCache.put(key, value);
    }
    
    public void delete(String key) {
        // 1. 删除 Redis
        redisTemplate.delete(key);
        
        // 2. 删除本地缓存
        localCache.invalidate(key);
        
        // 3. 发布失效消息（通知其他节点）
        redisTemplate.convertAndSend(CACHE_TOPIC, key);
    }
    
    private Object getFromDatabase(String key) {
        // 数据库查询逻辑
        return null;
    }
}
```

### 缓存一致性保障方案

**方案一：延迟双删**
```java
@Service
public class CacheConsistencyService {
    
    @Autowired
    private TwoLevelCacheService cacheService;
    
    @Autowired
    private UserMapper userMapper;
    
    @Transactional
    public void updateUser(User user) {
        String cacheKey = "user:" + user.getId();
        
        // 第一次删除缓存
        cacheService.delete(cacheKey);
        
        // 更新数据库
        userMapper.updateById(user);
        
        // 延迟500ms后再次删除（清理期间可能的脏读）
        CompletableFuture.runAsync(() -> {
            try {
                Thread.sleep(500);
                cacheService.delete(cacheKey);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });
    }
}
```

**方案三：设置短过期时间 + 版本号**
```java
@Service
public class VersionedCacheService {
    
    @Autowired
    private TwoLevelCacheService cacheService;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    public User getUserWithVersion(Long userId) {
        String cacheKey = "user:" + userId;
        String versionKey = "user:version:" + userId;
        
        // 获取缓存版本
        Long cacheVersion = (Long) redisTemplate.opsForValue().get(versionKey);
        
        // 获取缓存数据
        UserCache userCache = (UserCache) cacheService.get(cacheKey);
        
        if (userCache != null && Objects.equals(userCache.getVersion(), cacheVersion)) {
            return userCache.getUser();
        }
        
        // 版本不一致或缓存不存在，查数据库
        User user = getUserFromDatabase(userId);
        Long newVersion = System.currentTimeMillis();
        
        // 更新缓存和版本号
        redisTemplate.opsForValue().set(versionKey, newVersion, 1, TimeUnit.HOURS);
        cacheService.set(cacheKey, new UserCache(user, newVersion));
        
        return user;
    }
    
    public void updateUser(User user) {
        // 更新数据库
        updateDatabase(user);
        
        // 更新版本号（触发缓存失效）
        String versionKey = "user:version:" + user.getId();
        redisTemplate.opsForValue().set(versionKey, System.currentTimeMillis(), 1, TimeUnit.HOURS);
    }
    
    @Data
    @AllArgsConstructor
    static class UserCache {
        private User user;
        private Long version;
    }
}
```

## 20. 缓存三大问题：穿透、击穿、雪崩

### 缓存穿透（查询不存在的数据）

**问题场景**
```
恶意用户查询 id=-1 的商品
-> 缓存中没有
-> 数据库中也没有
-> 每次请求都打到数据库
-> 数据库压力剧增
```

**解决方案一：布隆过滤器**
```java
@Configuration
public class BloomFilterConfig {
    
    @Bean
    public BloomFilter<String> bloomFilter() {
        // 预期插入100万条数据，误判率0.01%
        BloomFilter<String> filter = BloomFilter.create(
            Funnels.stringFunnel(Charset.defaultCharset()),
            1000000,
            0.0001
        );
        
        // 初始化：加载所有存在的 ID
        List<String> allIds = loadAllIdsFromDatabase();
        allIds.forEach(filter::put);
        
        return filter;
    }
}

@Service
public class CachePenetrationService {
    
    @Autowired
    private BloomFilter<String> bloomFilter;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    public Product getProduct(Long productId) {
        String key = "product:" + productId;
        
        // 1. 先判断布隆过滤器
        if (!bloomFilter.mightContain(key)) {
            log.warn("布隆过滤器拦截非法请求: {}", productId);
            return null;
        }
        
        // 2. 查缓存
        Product product = (Product) redisTemplate.opsForValue().get(key);
        if (product != null) {
            return product;
        }
        
        // 3. 查数据库
        product = productMapper.selectById(productId);
        if (product != null) {
            redisTemplate.opsForValue().set(key, product, 1, TimeUnit.HOURS);
        }
        
        return product;
    }
    
    // 新增商品时更新布隆过滤器
    public void addProduct(Product product) {
        productMapper.insert(product);
        bloomFilter.put("product:" + product.getId());
    }
}
```

### 缓存击穿（热点 Key 过期）

**问题场景**
```
热门商品缓存过期
-> 瞬间大量请求同时访问
-> 所有请求都打到数据库
-> 数据库压力骤增
```

**解决方案一：互斥锁**
```java
@Service
public class CacheBreakdownService {
    
    @Autowired
    private RedissonClient redissonClient;
    
    public Product getProduct(Long productId) {
        String cacheKey = "product:" + productId;
        
        // 查缓存
        Product product = (Product) redisTemplate.opsForValue().get(cacheKey);
        if (product != null) {
            return product;
        }
        
        // 缓存不存在，加分布式锁
        String lockKey = "lock:product:" + productId;
        RLock lock = redissonClient.getLock(lockKey);
        
        try {
            // 尝试获取锁，最多等待3秒
            if (lock.tryLock(3, 10, TimeUnit.SECONDS)) {
                // 双重检查：可能其他线程已经加载
                product = (Product) redisTemplate.opsForValue().get(cacheKey);
                if (product != null) {
                    return product;
                }
                
                // 查数据库
                product = productMapper.selectById(productId);
                
                if (product != null) {
                    // 加载到缓存，随机过期时间防止同时失效
                    int expireTime = 3600 + new Random().nextInt(600);
                    redisTemplate.opsForValue().set(cacheKey, product, expireTime, TimeUnit.SECONDS);
                }
                
                return product;
            } else {
                // 获取锁失败，等待50ms后重试
                Thread.sleep(50);
                return getProduct(productId);
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new BusinessException("获取商品信息失败");
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
}
```

**解决方案二：逻辑过期（热点数据永不过期）**
```java
@Service
public class LogicalExpireService {
    
    @Data
    static class CacheData {
        private Object data;
        private Long expireTime;
    }
    
    private final ExecutorService executor = Executors.newFixedThreadPool(10);
    
    public Product getProduct(Long productId) {
        String cacheKey = "product:" + productId;
        
        // 查缓存
        CacheData cacheData = (CacheData) redisTemplate.opsForValue().get(cacheKey);
        
        if (cacheData == null){
            return null;
        }
        
        // 判断是否逻辑过期
        if (cacheData.getExpireTime() > System.currentTimeMillis()) {
            // 未过期，直接返回
            return (Product) cacheData.getData();
        }
        
        // 已过期，异步更新
        String lockKey = "lock:product:" + productId;
        if (tryLock(lockKey)) {
            executor.submit(() -> {
                try {
                    // 重建缓存
                    Product product = productMapper.selectById(productId);
                    CacheData newData = new CacheData();
                    newData.setData(product);
                    newData.setExpireTime(System.currentTimeMillis() + 3600000);
                    
                    // 永久存储，只是逻辑过期
                    redisTemplate.opsForValue().set(cacheKey, newData);
                } finally {
                    unlock(lockKey);
                }
            });
        }
        
        // 返回旧数据（降级）
        return (Product) cacheData.getData();
    }
    
    private boolean tryLock(String key) {
        Boolean success = redisTemplate.opsForValue().setIfAbsent(key, "1", 10, TimeUnit.SECONDS);
        return Boolean.TRUE.equals(success);
    }
    
    private void unlock(String key) {
        redisTemplate.delete(key);
    }
}
```

```
-> 凌晨3点所有缓存同时失效
-> 大量请求打到数据库
```

**解决方案二：多级缓存 + 限流降级**
```java
@Service
public class MultiLevelCacheService {
    
    @Autowired
    private Cache<String, Object> localCache; // Caffeine
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Autowired
    private RateLimiter rateLimiter; // Guava 限流器
    
    public Object get(String key) {
        // L1: 本地缓存（不过期）
        Object value = localCache.getIfPresent(key);
        if (value != null) {
            return value;
        }
        
        // L2: Redis 缓存
        value = redisTemplate.opsForValue().get(key);
        if (value != null) {
            localCache.put(key, value);
            return value;
        }
        
        // 限流：防止雪崩时数据库压力过大
        if (!rateLimiter.tryAcquire(1, 100, TimeUnit.MILLISECONDS)) {
            throw new BusinessException("系统繁忙，请稍后重试");
        }
        
        // L3: 数据库
        value = getFromDatabase(key);
        if (value != null) {
            int expire = 3600 + new Random().nextInt(600);
            redisTemplate.opsForValue().set(key, value, expire, TimeUnit.SECONDS);
            localCache.put(key, value);
        }
        
        return value;
    }
}
```

```java
@Service
public class CircuitBreakerCacheService {
    
    @Autowired
    private CircuitBreaker circuitBreaker; // Resilience4j
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    public Product getProduct(Long productId) {
        String key = "product:" + productId;
        
        try {
            // 使用熔断器包装 Redis 调用
            return circuitBreaker.executeSupplier(() -> {
                Product product = (Product) redisTemplate.opsForValue().get(key);
                if (product != null) {
                    return product;
                }
                
                // 查数据库
                product = productMapper.selectById(productId);
                if (product != null) {
                    int expire = 3600 + new Random().nextInt(600);
                    redisTemplate.opsForValue().set(key, product, expire, TimeUnit.SECONDS);
                }
                return product;
            });
        } catch (CallNotPermittedException e) {
            // 熔断器打开，降级处理
            log.warn("Redis 熔断，使用降级策略: {}", productId);
            return getProductFallback(productId);
        }
    }
    
    private Product getProductFallback(Long productId) {
        // 降级策略：返回默认数据或从备用数据源获取
        return productMapper.selectById(productId);
    }
}
```

### 项目中的综合方案

```java
@Service
public class ComprehensiveCacheService {
    
    @Autowired
    private BloomFilter<String> bloomFilter;
    
    @Autowired
    private Cache<String, Object> localCache;
    
    @Autowired
    private RedissonClient redissonClient;
    
    @Autowired
    private CircuitBreaker circuitBreaker;
    
    public Product getProduct(Long productId) {
        String cacheKey = "product:" + productId;
        
        // 1. 布隆过滤器（防穿透）
        if (!bloomFilter.mightContain(cacheKey)) {
            return null;
        }
        
        // 2. 本地缓存（防雪崩）
        Object cached = localCache.getIfPresent(cacheKey);
        if (cached != null) {
            return (Product) cached;
        }
        
        // 3. Redis 缓存 + 熔断（防雪崩）
        try {
            return circuitBreaker.executeSupplier(() -> {
                Object redisValue = redisTemplate.opsForValue().get(cacheKey);
                if (redisValue != null) {
                    localCache.put(cacheKey, redisValue);
                    return (Product) redisValue;
                }
                
                // 4. 分布式锁（防击穿）
                return loadWithLock(productId, cacheKey);
            });
        } catch (Exception e) {
            log.error("获取商品失败: {}", productId, e);
            return loadWithLock(productId, cacheKey);
        }
    }
    
    private Product loadWithLock(Long productId, String cacheKey) {
        RLock lock = redissonClient.getLock("lock:" + cacheKey);
        try {
            if (lock.tryLock(3, 10, TimeUnit.SECONDS)) {
                Product product = productMapper.selectById(productId);
                if (product != null) {
                    // 随机过期时间（防雪崩）
                    int expire = 3600 + new Random().nextInt(600);
                    redisTemplate.opsForValue().set(cacheKey, product, expire, TimeUnit.SECONDS);
                    localCache.put(cacheKey, product);
                    bloomFilter.put(cacheKey);
                }
                return product;
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
        return null;
    }
}
```
