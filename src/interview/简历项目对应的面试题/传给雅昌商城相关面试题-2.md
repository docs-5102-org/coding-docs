# SSO 单点登录面试题详解

## 32. 如何设计一套单点登录架构？基于 Redis 的 Token 登录机制是如何实现的？Token 的生成规则是什么？

### 单点登录（SSO）架构设计

#### 核心组件

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  应用系统A   │     │  应用系统B   │     │  应用系统C   │
└──────┬──────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                   │
       └───────────────────┼───────────────────┘
                           │
                    ┌──────▼──────┐
                    │  认证中心    │
                    │ (SSO Server)│
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │    Redis    │
                    │ (Token存储) │
                    └─────────────┘
```

#### 系统架构说明

**1. 认证中心（SSO Server）**
- 统一的用户认证服务
- 负责用户登录、Token生成与验证
- 管理用户会话状态

**2. 应用系统（Client Applications）**
- 各个业务系统
- 通过Token与认证中心交互
- 验证用户身份

**3. Redis存储**
- 存储Token与用户信息的映射
- 实现分布式Session共享
- 支持Token过期管理

### 基于 Redis 的 Token 登录机制实现

#### 完整流程

```Mermaid
sequenceDiagram
    actor User as 用户
    participant AppA as 应用A
    participant SSO as SSO认证中心
    participant Redis as Redis缓存
    participant AppB as 应用B

    Note over User,AppB: 首次登录应用A
    User->>AppA: 1. 访问应用A
    AppA->>AppA: 检查登录状态
    AppA-->>User: 2. 未登录，重定向到SSO
    
    User->>SSO: 3. 访问SSO登录页
    SSO-->>User: 显示登录表单
    User->>SSO: 4. 提交用户名密码
    
    SSO->>SSO: 验证用户凭证
    SSO->>SSO: 5. 生成Token
    SSO->>Redis: 6. 存储Token及用户信息
    Redis-->>SSO: 存储成功
    
    SSO-->>User: 7. 重定向回应用A(携带Token)
    User->>AppA: 访问应用A(携带Token)
    AppA->>Redis: 8. 验证Token有效性
    Redis-->>AppA: Token有效，返回用户信息
    AppA->>AppA: 9. 设置本地Session
    AppA-->>User: 登录成功，显示应用A内容

    Note over User,AppB: 访问应用B（单点登录）
    User->>AppB: 10. 访问应用B(携带Token)
    AppB->>Redis: 11. 验证Token有效性
    Redis-->>AppB: Token有效，返回用户信息
    AppB->>AppB: 设置本地Session
    AppB-->>User: 免登录，直接显示应用B内容
```

#### Java 实现示例

```java
@Service
public class SSOTokenService {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    private static final String TOKEN_PREFIX = "sso:token:";
    private static final String USER_TOKEN_PREFIX = "sso:user:token:";
    private static final long TOKEN_EXPIRE_TIME = 7200; // 2小时
    
    /**
     * 用户登录，生成Token
     */
    public TokenResponse login(String username, String password) {
        // 1. 验证用户名密码
        User user = validateUser(username, password);
        if (user == null) {
            throw new AuthenticationException("用户名或密码错误");
        }
        
        // 2. 生成Token
        String token = generateToken(user);
        
        // 3. 构建Token数据
        TokenData tokenData = TokenData.builder()
            .userId(user.getId())
            .username(user.getUsername())
            .loginTime(System.currentTimeMillis())
            .build();
        
        // 4. 存储到Redis
        // Token -> 用户信息
        String tokenKey = TOKEN_PREFIX + token;
        redisTemplate.opsForValue().set(
            tokenKey, 
            tokenData, 
            TOKEN_EXPIRE_TIME, 
            TimeUnit.SECONDS
        );
        
        // 用户 -> Token（支持单点登录踢出）
        String userTokenKey = USER_TOKEN_PREFIX + user.getId();
        redisTemplate.opsForValue().set(
            userTokenKey, 
            token, 
            TOKEN_EXPIRE_TIME, 
            TimeUnit.SECONDS
        );
        
        return TokenResponse.builder()
            .token(token)
            .expireTime(TOKEN_EXPIRE_TIME)
            .build();
    }
    
    /**
     * 验证Token
     */
    public TokenData validateToken(String token) {
        String tokenKey = TOKEN_PREFIX + token;
        TokenData tokenData = (TokenData) redisTemplate.opsForValue().get(tokenKey);
        
        if (tokenData == null) {
            throw new TokenExpiredException("Token已过期或不存在");
        }
        
        return tokenData;
    }
    
    /**
     * 退出登录
     */
    public void logout(String token) {
        String tokenKey = TOKEN_PREFIX + token;
        TokenData tokenData = (TokenData) redisTemplate.opsForValue().get(tokenKey);
        
        if (tokenData != null) {
            // 删除Token
            redisTemplate.delete(tokenKey);
            // 删除用户Token映射
            String userTokenKey = USER_TOKEN_PREFIX + tokenData.getUserId();
            redisTemplate.delete(userTokenKey);
        }
    }
}
```

### Token 生成规则

#### 方案一：UUID + 时间戳 + 用户ID（推荐）

```java
public String generateToken(User user) {
    // UUID保证唯一性
    String uuid = UUID.randomUUID().toString().replace("-", "");
    
    // 时间戳
    long timestamp = System.currentTimeMillis();
    
    // 用户ID
    String userId = String.valueOf(user.getId());
    
    // 组合并加密
    String rawToken = uuid + "_" + timestamp + "_" + userId;
    
    // 使用HMAC-SHA256签名，防止篡改
    String signature = HmacUtils.hmacSha256Hex(SECRET_KEY, rawToken);
    
    return rawToken + "_" + signature;
}
```

#### 方案二：JWT Token（无状态）

```java
public String generateJWTToken(User user) {
    Map<String, Object> claims = new HashMap<>();
    claims.put("userId", user.getId());
    claims.put("username", user.getUsername());
    claims.put("roles", user.getRoles());
    
    return Jwts.builder()
        .setClaims(claims)
        .setSubject(user.getUsername())
        .setIssuedAt(new Date())
        .setExpiration(new Date(System.currentTimeMillis() + TOKEN_EXPIRE_TIME * 1000))
        .signWith(SignatureAlgorithm.HS256, SECRET_KEY)
        .compact();
}
```

#### 方案三：雪花算法 + 加密

```java
public String generateSnowflakeToken(User user) {
    // 使用雪花算法生成唯一ID
    long snowflakeId = snowflakeIdWorker.nextId();
    
    // 组合用户信息
    String tokenData = snowflakeId + "|" + user.getId() + "|" + System.currentTimeMillis();
    
    // AES加密
    return AESUtil.encrypt(tokenData, SECRET_KEY);
}
```

#### Token 生成规则对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| UUID + 签名 | 简单、安全、可验证 | 需要Redis存储 | 一般Web应用 |
| JWT | 无状态、自包含 | Token较长、无法主动失效 | 微服务、API |
| 雪花算法 | 高性能、有序 | 需要加密、依赖时钟 | 高并发系统 |

## 33. Token 的过期策略是怎样的？如何实现 Token 的续期？

### Token 过期策略

#### 策略一：固定过期时间（简单）

```java
@Service
public class FixedExpireStrategy {
    
    private static final long TOKEN_EXPIRE_TIME = 7200; // 2小时固定过期
    
    public void setToken(String token, TokenData tokenData) {
        String key = TOKEN_PREFIX + token;
        redisTemplate.opsForValue().set(
            key, 
            tokenData, 
            TOKEN_EXPIRE_TIME, 
            TimeUnit.SECONDS
        );
    }
}
```

**优点：** 实现简单，逻辑清晰  
**缺点：** 用户体验差，可能在操作中途过期

#### 策略二：滑动过期时间（推荐）

```java
@Service
public class SlidingExpireStrategy {
    
    private static final long TOKEN_EXPIRE_TIME = 7200; // 2小时
    private static final long REFRESH_THRESHOLD = 1800; // 30分钟内自动续期
    
    /**
     * 验证Token并自动续期
     */
    public TokenData validateAndRefresh(String token) {
        String tokenKey = TOKEN_PREFIX + token;
        TokenData tokenData = (TokenData) redisTemplate.opsForValue().get(tokenKey);
        
        if (tokenData == null) {
            throw new TokenExpiredException("Token已过期");
        }
        
        // 获取剩余过期时间
        Long expireTime = redisTemplate.getExpire(tokenKey, TimeUnit.SECONDS);
        
        // 如果剩余时间小于阈值，自动续期
        if (expireTime != null && expireTime < REFRESH_THRESHOLD) {
            redisTemplate.expire(tokenKey, TOKEN_EXPIRE_TIME, TimeUnit.SECONDS);
            
            // 同步更新用户Token映射的过期时间
            String userTokenKey = USER_TOKEN_PREFIX + tokenData.getUserId();
            redisTemplate.expire(userTokenKey, TOKEN_EXPIRE_TIME, TimeUnit.SECONDS);
        }
        
        return tokenData;
    }
}
```

#### 策略三：双Token机制（Access Token + Refresh Token）

```java
@Service
public class DualTokenStrategy {
    
    private static final long ACCESS_TOKEN_EXPIRE = 1800;  // 30分钟
    private static final long REFRESH_TOKEN_EXPIRE = 604800; // 7天
    
    /**
     * 登录时生成双Token
     */
    public DualTokenResponse login(User user) {
        // 生成Access Token（短期）
        String accessToken = generateToken("access");
        TokenData accessData = buildTokenData(user);
        redisTemplate.opsForValue().set(
            TOKEN_PREFIX + "access:" + accessToken,
            accessData,
            ACCESS_TOKEN_EXPIRE,
            TimeUnit.SECONDS
        );
        
        // 生成Refresh Token（长期）
        String refreshToken = generateToken("refresh");
        TokenData refreshData = buildTokenData(user);
        redisTemplate.opsForValue().set(
            TOKEN_PREFIX + "refresh:" + refreshToken,
            refreshData,
            REFRESH_TOKEN_EXPIRE,
            TimeUnit.SECONDS
        );
        
        return DualTokenResponse.builder()
            .accessToken(accessToken)
            .refreshToken(refreshToken)
            .accessExpire(ACCESS_TOKEN_EXPIRE)
            .refreshExpire(REFRESH_TOKEN_EXPIRE)
            .build();
    }
    
    /**
     * 使用Refresh Token刷新Access Token
     */
    public String refreshAccessToken(String refreshToken) {
        String refreshKey = TOKEN_PREFIX + "refresh:" + refreshToken;
        TokenData tokenData = (TokenData) redisTemplate.opsForValue().get(refreshKey);
        
        if (tokenData == null) {
            throw new TokenExpiredException("Refresh Token已过期，请重新登录");
        }
        
        // 生成新的Access Token
        String newAccessToken = generateToken("access");
        redisTemplate.opsForValue().set(
            TOKEN_PREFIX + "access:" + newAccessToken,
            tokenData,
            ACCESS_TOKEN_EXPIRE,
            TimeUnit.SECONDS
        );
        
        return newAccessToken;
    }
}
```

### Token 续期实现方案

#### 方案一：拦截器自动续期

```java
@Component
public class TokenRefreshInterceptor implements HandlerInterceptor {
    
    @Autowired
    private SSOTokenService tokenService;
    
    @Override
    public boolean preHandle(HttpServletRequest request, 
                            HttpServletResponse response, 
                            Object handler) {
        String token = request.getHeader("Authorization");
        
        if (StringUtils.hasText(token)) {
            try {
                // 验证并自动续期
                tokenService.validateAndRefresh(token);
            } catch (TokenExpiredException e) {
                response.setStatus(HttpStatus.UNAUTHORIZED.value());
                return false;
            }
        }
        
        return true;
    }
}
```

#### 方案二：前端主动刷新

```javascript
// 前端定时刷新Token
class TokenManager {
    constructor() {
        this.accessToken = localStorage.getItem('accessToken');
        this.refreshToken = localStorage.getItem('refreshToken');
        this.startRefreshTimer();
    }
    
    // 启动定时刷新（在Token过期前5分钟刷新）
    startRefreshTimer() {
        setInterval(async () => {
            await this.refreshAccessToken();
        }, 25 * 60 * 1000); // 25分钟刷新一次（假设30分钟过期）
    }
    
    async refreshAccessToken() {
        try {
            const response = await fetch('/api/token/refresh', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json'
                },
                body: JSON.stringify({
                    refreshToken: this.refreshToken
                })
            });
            
            const data = await response.json();
            this.accessToken = data.accessToken;
            localStorage.setItem('accessToken', data.accessToken);
        } catch (error) {
            console.error('Token刷新失败', error);
            // 跳转到登录页
            window.location.href = '/login';
        }
    }
}
```

#### 方案三：响应拦截器刷新

```javascript
// Axios响应拦截器
axios.interceptors.response.use(
    response => response,
    async error => {
        const originalRequest = error.config;
        
        // Token过期，尝试刷新

                originalRequest.headers['Authorization'] = `Bearer ${accessToken}`;
                return axios(originalRequest);
            } catch (refreshError) {
                // 刷新失败，跳转登录
                window.location.href = '/login';
                return Promise.reject(refreshError);
            }
        }
        
        return Promise.reject(error);
    }
);
```

#### 2. Token 签名验证

```java
@Service
public class TokenSignatureService {
    
    private static final String SECRET_KEY = "your-secret-key-min-256-bits";
    
    /**
     * 生成带签名的Token
     */
    public String generateSignedToken(User user) {
        // Token主体
        String tokenBody = UUID.randomUUID().toString() + 
                          "_" + user.getId() + 
                          "_" + System.currentTimeMillis();
        
        // HMAC-SHA256签名
        String signature = HmacUtils.hmacSha256Hex(SECRET_KEY, tokenBody);
        
        return tokenBody + "." + signature;
    }
    
    /**
     * 验证Token签名
     */
    public boolean verifySignature(String token) {
        String[] parts = token.split("\\.");
        if (parts.length != 2) {
            return false;
        }
        
        String tokenBody = parts[0];
        String signature = parts[1];
        
        // 重新计算签名
        String expectedSignature = HmacUtils.hmacSha256Hex(SECRET_KEY, tokenBody);
        
        // 防止时序攻击的安全比较
        return MessageDigest.isEqual(
            signature.getBytes(),
            expectedSignature.getBytes()
        );
    }
}
```

```java
@Service
public class IPBindingService {

     * 验证Token时检查IP
     */

        TokenData tokenData = (TokenData) redisTemplate.opsForValue()
            .get(TOKEN_PREFIX + token);
        
        if (tokenData == null) {
            throw new TokenExpiredException("Token已过期");
        }
        
        // 严格模式：IP必须完全匹配
        if (!tokenData.getIpAddress().equals(currentIP)) {
            // 记录异常日志
            logSecurityEvent("IP不匹配", token, tokenData.getIpAddress(), currentIP);
            throw new SecurityException("Token IP不匹配，可能被盗用");
        }
        
        return tokenData;
    }
    
    /**
     * 宽松模式：IP段匹配（适用于移动网络）
     */
    public boolean isIPRangeMatch(String loginIP, String currentIP) {
        String[] loginParts = loginIP.split("\\.");
        String[] currentParts = currentIP.split("\\.");
        
        // 比较前三段（C类地址）
        return loginParts[0].equals(currentParts[0]) &&
               loginParts[1].equals(currentParts[1]) &&
               loginParts[2].equals(currentParts[2]);
    }
}
```

```java
@Service
public class TokenEncryptionService {
    
    private static final String AES_KEY = "your-32-byte-aes-key-here-!!";
    
    /**
     * 加密Token存储
     */
    public void storeEncryptedToken(String token, TokenData tokenData) {
        try {
            // 序列化TokenData
            String jsonData = objectMapper.writeValueAsString(tokenData);
            
            // AES加密

            // 存储加密数据
            redisTemplate.opsForValue().set(

                encryptedData,
                TOKEN_EXPIRE_TIME,
                TimeUnit.SECONDS
            );
        } catch (Exception e) {
            throw new RuntimeException("Token加密失败", e);
        }
    }
    
    /**
     * 解密Token
     */
    public TokenData getDecryptedToken(String token) {
        try {
            String encryptedData = (String) redisTemplate.opsForValue()
                .get(TOKEN_PREFIX + token);
            
            if (encryptedData == null) {
                return null;
            }
            
            // AES解密
            String jsonData = AESUtil.decrypt(encryptedData, AES_KEY);
            
            // 反序列化
            return objectMapper.readValue(jsonData, TokenData.class);
        } catch (Exception e) {
            throw new RuntimeException("Token解密失败", e);
        }
    }
}
```

```java
@Service
public class TokenBlacklistService {
    
    private static final String BLACKLIST_PREFIX = "sso:blacklist:";
    
    /**
     * 将Token加入黑名单
     */
    public void addToBlacklist(String token, String reason) {
        // 获取Token剩余过期时间
        Long expireTime = redisTemplate.getExpire(
            TOKEN_PREFIX + token, 
            TimeUnit.SECONDS
        );
        
        if (expireTime != null && expireTime > 0) {
            BlacklistEntry entry = BlacklistEntry.builder()
                .token(token)
                .reason(reason)
                .blacklistedAt(System.currentTimeMillis())
                .build();
            
            // 加入黑名单，过期时间与Token一致
            redisTemplate.opsForValue().set(
                BLACKLIST_PREFIX + token,
                entry,
                expireTime,
                TimeUnit.SECONDS
            );
        }
    }
    
    /**
     * 检查Token是否在黑名单中
     */
    public boolean isBlacklisted(String token) {
        return redisTemplate.hasKey(BLACKLIST_PREFIX + token);
    }
    
    /**
     * 强制下线用户所有Token
     */
    public void forceLogoutUser(Long userId) {
        // 获取用户所有Token
        Set<String> tokens = getUserTokens(userId);
        
        for (String token : tokens) {
            addToBlacklist(token, "管理员强制下线");
            // 删除Token
            redisTemplate.delete(TOKEN_PREFIX + token);
        }
    }
}
```

#### 7. 限流与异常检测

```java
@Service
public class TokenSecurityMonitor {
    
    private static final String RATE_LIMIT_PREFIX = "sso:rate:";
    private static final int MAX_REQUESTS_PER_MINUTE = 60;
    
    /**
     * Token使用频率限制
     */
    public boolean checkRateLimit(String token) {
        String key = RATE_LIMIT_PREFIX + token;
        Long count = redisTemplate.opsForValue().increment(key);
        
        if (count == 1) {
            redisTemplate.expire(key, 1, TimeUnit.MINUTES);
        }
        
        if (count > MAX_REQUESTS_PER_MINUTE) {
            logSecurityEvent("Token使用频率异常", token);
            return false;
        }
        
        return true;
    }
    
    /**
     * 异常登录检测
     */
    public void detectAnomalousLogin(TokenData tokenData, HttpServletRequest request) {
        String currentIP = getClientIP(request);
        String currentLocation = getLocationByIP(currentIP);
        
        // 检查是否有历史登录记录
        String lastLoginKey = "sso:last:login:" + tokenData.getUserId();
        LoginRecord lastLogin = (LoginRecord) redisTemplate.opsForValue().get(lastLoginKey);
        
        if (lastLogin != null) {
            // 检测异常情况
            if (isDifferentCountry(lastLogin.getLocation(), currentLocation)) {
                // 发送安全警告
                sendSecurityAlert(tokenData.getUserId(), "检测到异地登录");
                
                // 可选：要求二次验证
                requireTwoFactorAuth(tokenData.getUserId());
            }
        }
        
        // 更新最后登录记录
        LoginRecord currentLogin = LoginRecord.builder()
            .userId(tokenData.getUserId())
            .ipAddress(currentIP)
            .location(currentLocation)
            .loginTime(System.currentTimeMillis())
            .build();
        
        redisTemplate.opsForValue().set(lastLoginKey, currentLogin, 30, TimeUnit.DAYS);
    }
```

```javascript
    // 推荐存储在 HttpOnly Cookie 或内存中
    
    constructor() {
        this.token = null;

        // 请求时浏览器自动携带
        return this.token;
    }
    
    // 如果必须在前端存储，使用加密
    storeTokenSecurely(token) {
        // 使用Web Crypto API加密
        const encryptedToken = this.encryptToken(token);
        sessionStorage.setItem('_st', encryptedToken);
    }
    
    async encryptToken(token) {
        const key = await this.getEncryptionKey();
        const encoded = new TextEncoder().encode(token);
        const encrypted = await crypto.subtle.encrypt(
            { name: 'AES-GCM', iv: new Uint8Array(12) },
            key,
            encoded
        );
        return btoa(String.fromCharCode(...new Uint8Array(encrypted)));
    }
}
```

```java
@Service
public class ComprehensiveTokenSecurity {
    
    /**
     * 综合安全验证
     */
    public TokenData validateTokenSecurely(String token, HttpServletRequest request) {
        // 1. 检查黑名单
        if (tokenBlacklistService.isBlacklisted(token)) {
            throw new SecurityException("Token已被禁用");
        }
        
        // 2. 验证签名
        if (!tokenSignatureService.verifySignature(token)) {
            throw new SecurityException("Token签名无效");
        }
        
        // 3. 限流检查
        if (!tokenSecurityMonitor.checkRateLimit(token)) {
            throw new SecurityException("Token使用频率异常");
        }
        
        // 4. 解密获取数据
        TokenData tokenData = tokenEncryptionService.getDecryptedToken(token);
        if (tokenData == null) {
            throw new TokenExpiredException("Token不存在或已过期");
        }
        
        // 5. IP验证
        String currentIP = getClientIP(request);
        if (!ipBindingService.isIPRangeMatch(tokenData.getIpAddress(), currentIP)) {
            logSecurityEvent("IP异常", token, tokenData.getIpAddress(), currentIP);
            // 可以选择拒绝或要求二次验证
        }
        
        // 6. 设备指纹验证
        if (!deviceFingerprintService.validateFingerprint(token, request)) {
            logSecurityEvent("设备指纹不匹配", token);
        }
        
        // 7. 异常检测
        tokenSecurityMonitor.detectAnomalousLogin(tokenData, request);
        
        return tokenData;
    }
}
```

```java
@Service
public class SingleDeviceLoginStrategy {
    
    private static final String USER_TOKEN_PREFIX = "sso:user:token:";
    
    /**
     * 登录时踢出其他设备
     */
    public String loginWithKickout(User user, HttpServletRequest request) {
        Long userId = user.getId();
        
        // 1. 检查是否有旧Token
        String oldTokenKey = USER_TOKEN_PREFIX + userId;
        String oldToken = (String) redisTemplate.opsForValue().get(oldTokenKey);
        
        if (oldToken != null) {
            // 2. 将旧Token加入黑名单
            tokenBlacklistService.addToBlacklist(oldToken, "新设备登录");
            
            // 3. 删除旧Token数据
            redisTemplate.delete(TOKEN_PREFIX + oldToken);
            // 4. 可选：通过WebSocket通知旧设备下线
            notifyDeviceLogout(oldToken, "您的账号在其他设备登录");
        }
        
        // 5. 生成新Token
        String newToken = generateToken(user);
        TokenData tokenData = buildTokenData(user, request);
        
        // 6. 存储新Token
        redisTemplate.opsForValue().set(
            TOKEN_PREFIX + newToken,
            tokenData,
            TOKEN_EXPIRE_TIME,
            TimeUnit.SECONDS
        );
        
        // 7. 更新用户当前Token
        redisTemplate.opsForValue().set(
            oldTokenKey,
            newToken,
            TOKEN_EXPIRE_TIME,
            TimeUnit.SECONDS
        );
        
        return newToken;
    }
    
    /**
     * WebSocket通知旧设备
     */
    private void notifyDeviceLogout(String token, String message) {
        // 通过WebSocket推送消息
        webSocketService.sendToToken(token, new LogoutNotification(message));
    }
}
```

```java
@Service
public class MultiDeviceLoginStrategy {
    
    private static final String USER_DEVICES_PREFIX = "sso:user:devices:";
    private static final int MAX_DEVICES = 5; // 最多允许5个设备
    
    /**
     * 支持多设备登录
     */
    public String loginMultiDevice(User user, HttpServletRequest request) {
        Long userId = user.getId();
        String devicesKey = USER_DEVICES_PREFIX + userId;
        
        // 1. 获取用户所有设备
        Set<DeviceToken> devices = getDeviceTokens(devicesKey);
        
        // 2. 生成设备ID
        String deviceId = generateDeviceId(request);
        
        // 3. 检查设备数量限制
        if (devices.size() >= MAX_DEVICES) {
            // 踢出最早登录的设备
            DeviceToken oldestDevice = devices.stream()
                .min(Comparator.comparing(DeviceToken::getLoginTime))
                .orElse(null);
            
            if (oldestDevice != null) {
                removeDevice(devicesKey, oldestDevice);
                tokenBlacklistService.addToBlacklist(
                    oldestDevice.getToken(), 
                    "超过设备数量限制"
                );
            }
        }
        
        // 4. 生成新Token
        String newToken = generateToken(user);
        TokenData tokenData = buildTokenData(user, request);
        tokenData.setDeviceId(deviceId);
        
        // 5. 存储Token
        redisTemplate.opsForValue().set(
            TOKEN_PREFIX + newToken,
            tokenData,
            TOKEN_EXPIRE_TIME,
            TimeUnit.SECONDS
        );
        
        // 6. 添加到设备列表
        DeviceToken deviceToken = DeviceToken.builder()
            .token(newToken)
            .deviceId(deviceId)
            .deviceName(getDeviceName(request))
            .deviceType(getDeviceType(request))
            .ipAddress(getClientIP(request))
            .loginTime(System.currentTimeMillis())
            .build();
        
        addDevice(devicesKey, deviceToken);
        
        return newToken;
    }
    
    /**
     * 生成设备ID
     */
    private String generateDeviceId(HttpServletRequest request) {
        String userAgent = request.getHeader("User-Agent");
        String ip = getClientIP(request);
        String raw = userAgent + "|" + ip;
        return DigestUtils.md5Hex(raw);
    }
    
    /**
     * 获取设备名称
     */
    private String getDeviceName(HttpServletRequest request) {
        String userAgent = request.getHeader("User-Agent");
        if (userAgent.contains("iPhone")) return "iPhone";
        if (userAgent.contains("Android")) return "Android";
        if (userAgent.contains("Windows")) return "Windows PC";
        if (userAgent.contains("Mac")) return "Mac";
        return "Unknown Device";
    }
}
```

```java
@Service
public class UserChoiceStrategy {
    
    /**
     * 登录时检测到其他设备，返回设备列表让用户选择
     */
    public LoginResponse loginWithChoice(User user, HttpServletRequest request) {
        Long userId = user.getId();
        String devicesKey = USER_DEVICES_PREFIX + userId;
        Set<DeviceToken> devices = getDeviceTokens(devicesKey);
        
        if (!devices.isEmpty()) {
            // 生成临时验证码
            String verificationCode = generateVerificationCode();
            String codeKey = "sso:login:verification:" + userId;
            
            // 存储待登录信息
            PendingLogin pendingLogin = PendingLogin.builder()
                .userId(userId)
                .verificationCode(verificationCode)
                .newDeviceInfo(getDeviceInfo(request))
                .existingDevices(devices)
                .createTime(System.currentTimeMillis())
                .build();
            
            redisTemplate.opsForValue().set(
                codeKey,
                pendingLogin,
                5,
                TimeUnit.MINUTES
            );
            
            // 返回需要用户选择
            return LoginResponse.builder()
                .status("REQUIRE_CHOICE")
                .verificationCode(verificationCode)
                .existingDevices(devices)
                .message("检测到其他设备登录，请选择操作")
                .build();
        }
        
        // 没有其他设备，直接登录
        String token = doLogin(user, request);
        return LoginResponse.builder()
            .status("SUCCESS")
            .token(token)
            .build();
    }
    
    /**
     * 用户确认登录选择
     */
    public String confirmLogin(Long userId, String verificationCode, LoginAction action) {
        String codeKey = "sso:login:verification:" + userId;
        PendingLogin pendingLogin = (PendingLogin) redisTemplate.opsForValue().get(codeKey);
        
        if (pendingLogin == null || !pendingLogin.getVerificationCode().equals(verificationCode)) {
            throw new SecurityException("验证码无效或已过期");
        }
        
        String devicesKey = USER_DEVICES_PREFIX + userId;
        
        switch (action) {
            case KICK_ALL:
                // 踢出所有设备
                for (DeviceToken device : pendingLogin.getExistingDevices()) {
                    tokenBlacklistService.addToBlacklist(device.getToken(), "用户选择踢出");
                }
                redisTemplate.delete(devicesKey);
                break;
                
            case KICK_SELECTED:
                // 踢出选中的设备
                List<String> selectedTokens = action.getSelectedTokens();
                for (String token : selectedTokens) {
                    tokenBlacklistService.addToBlacklist(token, "用户选择踢出");
                }
                break;
                
            case COEXIST:
                // 共存，不踢出任何设备
                break;
                
            default:
                throw new IllegalArgumentException("未知的登录操作");
        }
        
        // 清除验证码
        redisTemplate.delete(codeKey);
        
        // 执行登录
        return doLogin(pendingLogin.getUserId(), pendingLogin.getNewDeviceInfo());
    }
}
```

```java
@Service
public class DeviceManagementService {
    
    public List<DeviceInfo> getUserDevices(Long userId) {
        String devicesKey = USER_DEVICES_PREFIX + userId;
        Set<DeviceToken> deviceTokens = getDeviceTokens(devicesKey);
        
        return deviceTokens.stream()
            .map(this::convertToDeviceInfo)
            .sorted(Comparator.comparing(DeviceInfo::getLoginTime).reversed())
            .collect(Collectors.toList());
    }
    
    public void kickoutDevice(Long userId, String deviceId) {
        String devicesKey = USER_DEVICES_PREFIX + userId;
        Set<DeviceToken> devices = getDeviceTokens(devicesKey);
        
        Optional<DeviceToken> targetDevice = devices.stream()
            .filter(d -> d.getDeviceId().equals(deviceId))
            .findFirst();
        
        if (targetDevice.isPresent()) {
            DeviceToken device = targetDevice.get();
            
            // 加入黑名单
            tokenBlacklistService.addToBlacklist(device.getToken(), "用户主动踢出");
            
            // 删除Token
            redisTemplate.delete(TOKEN_PREFIX + device.getToken());
            
            // 从设备列表移除
            removeDevice(devicesKey, device);
            
            // 通知设备
            notifyDeviceLogout(device.getToken(), "您已被踢出登录");
        }
    }
    
    private DeviceInfo convertToDeviceInfo(DeviceToken deviceToken) {
        return DeviceInfo.builder()
            .deviceId(deviceToken.getDeviceId())
            .deviceName(deviceToken.getDeviceName())
            .deviceType(deviceToken.getDeviceType())
            .ipAddress(deviceToken.getIpAddress())
            .location(getLocationByIP(deviceToken.getIpAddress()))
            .loginTime(deviceToken.getLoginTime())
            .lastActiveTime(getTokenLastActiveTime(deviceToken.getToken()))
            .isCurrent(isCurrentDevice(deviceToken.getToken()))
            .build();
    }
```

### 策略对比总结

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 互踢模式 | 安全性高、逻辑简单 | 用户体验差 | 金融、支付类应用 |
| 共存模式 | 用户体验好 | 安全风险较高 | 社交、内容类应用 |
| 类型限制 | 平衡安全与体验 | 实现复杂 | 企业办公系统 |
| 用户选择 | 灵活、用户友好 | 流程繁琐 | 对安全敏感的应用 |

### 推荐方案

**综合推荐：** 类型限制模式 + 设备管理功能

- PC端允许1个设备
- 移动端允许2个设备（考虑多个手机）
- 提供设备管理界面，用户可主动踢出
- 异常登录时需要二次验证

这样既保证了安全性，又兼顾了用户体验。
