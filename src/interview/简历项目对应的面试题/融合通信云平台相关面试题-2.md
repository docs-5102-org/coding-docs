# 融合通信云平台相关面试题-优惠券系统面试题详解

## 优惠券中心的核心功能模块和数据库设计

### 核心功能模块

**1. 优惠券模板管理模块**
- 创建、编辑、删除优惠券模板
- 设置优惠规则（满减、折扣、立减等）
- 配置发放策略和有效期

**2. 优惠券发放模块**
- 主动发放（运营后台批量发放）
- 被动领取（用户主动领取）
- 自动发放（注册送、生日送等）

**3. 优惠券领取模块**
- 领取资格校验
- 库存扣减
- 领取记录生成
- 防重复领取

**4. 优惠券使用模块**
- 订单适用性校验
- 优惠计算
- 优惠券核销
- 使用记录追踪

**5. 优惠券查询模块**
- 用户优惠券列表
- 可用优惠券筛选
- 优惠券详情查询

### 表设计要点

1. **分离模板和实例**：template表存储规则，user_coupon表存储用户持有的券
2. **独立库存表**：便于高并发库存扣减，减少锁竞争
3. **冗余适当数据**：user_coupon中冗余优惠金额等，便于查询统计
4. **索引设计**：根据查询场景建立合适索引，如用户券列表、订单核销等
5. **分表策略**：user_coupon和日志表可按用户ID或时间分表

## 7. Redis + Lua 实现库存扣减和防超发

### Lua 脚本实现

```lua
-- 优惠券库存扣减 Lua 脚本
-- KEYS[1]: 库存key，如 "coupon:stock:123"
-- KEYS[2]: 用户领取记录key，如 "coupon:user:领取:123"
-- ARGV[1]: 用户ID
-- ARGV[2]: 每人限领数量
-- ARGV[3]: 当前时间戳

local stock_key = KEYS[1]
local user_receive_key = KEYS[2]
local user_id = ARGV[1]
local per_user_limit = tonumber(ARGV[2])
local current_time = ARGV[3]

-- 1. 检查库存是否存在
local stock = redis.call('GET', stock_key)
if not stock then
    return {err = 'STOCK_NOT_EXIST'}
end

stock = tonumber(stock)

-- 2. 检查库存是否充足
if stock <= 0 then
    return {err = 'STOCK_NOT_ENOUGH'}
end

-- 3. 检查用户领取次数
local user_receive_count = redis.call('HGET', user_receive_key, user_id)
if user_receive_count then
    user_receive_count = tonumber(user_receive_count)
    if user_receive_count >= per_user_limit then
        return {err = 'EXCEED_USER_LIMIT'}
    end
else
    user_receive_count = 0
end

-- 4. 扣减库存
local new_stock = redis.call('DECR', stock_key)

-- 5. 增加用户领取次数
redis.call('HINCRBY', user_receive_key, user_id, 1)

-- 6. 设置过期时间（防止内存泄漏）
redis.call('EXPIRE', user_receive_key, 86400 * 7) -- 7天过期

-- 返回成功和剩余库存
return {ok = 'SUCCESS', stock = new_stock}
```

### Java 调用示例

```java
@Service
public class CouponStockService {
    
    @Autowired
    private StringRedisTemplate redisTemplate;
    
    private static final String LUA_SCRIPT = 
        "local stock_key = KEYS[1]\n" +
        "local user_receive_key = KEYS[2]\n" +
        "local user_id = ARGV[1]\n" +
        "local per_user_limit = tonumber(ARGV[2])\n" +
        "local stock = redis.call('GET', stock_key)\n" +
        "if not stock then\n" +
        "    return {err = 'STOCK_NOT_EXIST'}\n" +
        "end\n" +
        "stock = tonumber(stock)\n" +
        "if stock <= 0 then\n" +
        "    return {err = 'STOCK_NOT_ENOUGH'}\n" +
        "end\n" +
        "local user_receive_count = redis.call('HGET', user_receive_key, user_id)\n" +
        "if user_receive_count then\n" +
        "    user_receive_count = tonumber(user_receive_count)\n" +
        "    if user_receive_count >= per_user_limit then\n" +
        "        return {err = 'EXCEED_USER_LIMIT'}\n" +
        "    end\n" +
        "end\n" +
        "local new_stock = redis.call('DECR', stock_key)\n" +
        "redis.call('HINCRBY', user_receive_key, user_id, 1)\n" +
        "redis.call('EXPIRE', user_receive_key, 604800)\n" +
        "return {ok = 'SUCCESS', stock = new_stock}";
    
    private DefaultRedisScript<List> redisScript;
    
    @PostConstruct
    public void init() {
        redisScript = new DefaultRedisScript<>();
        redisScript.setScriptText(LUA_SCRIPT);
        redisScript.setResultType(List.class);
    }
    
    /**
     * 扣减优惠券库存
     */
    public CouponReceiveResult deductStock(Long templateId, Long userId, Integer perUserLimit) {
        String stockKey = "coupon:stock:" + templateId;
        String userReceiveKey = "coupon:user:receive:" + templateId;
        
        List<String> keys = Arrays.asList(stockKey, userReceiveKey);
        Object[] args = {userId.toString(), perUserLimit.toString(), 
                        String.valueOf(System.currentTimeMillis())};
        
        try {
            List result = redisTemplate.execute(redisScript, keys, args);
            
            if (result == null || result.isEmpty()) {
                return CouponReceiveResult.fail("系统异常");
            }
            
            // 解析返回结果
            if (result.size() == 2 && "err".equals(result.get(0))) {
                String errorCode = (String) result.get(1);
                return handleError(errorCode);
            }
            
            if (result.size() >= 2 && "ok".equals(result.get(0))) {
                return CouponReceiveResult.success();
            }
            
            return CouponReceiveResult.fail("未知错误");
            
        } catch (Exception e) {
            log.error("Redis扣减库存失败", e);
            return CouponReceiveResult.fail("系统繁忙");
        }
    }
    
    private CouponReceiveResult handleError(String errorCode) {
        switch (errorCode) {
            case "STOCK_NOT_EXIST":
                return CouponReceiveResult.fail("优惠券不存在");
            case "STOCK_NOT_ENOUGH":
                return CouponReceiveResult.fail("优惠券已抢完");
            case "EXCEED_USER_LIMIT":
                return CouponReceiveResult.fail("您已达到领取上限");
            default:
                return CouponReceiveResult.fail("领取失败");
        }
    }
}
```

### 为什么选择 Lua？

**1. 原子性保证**
- Lua脚本在Redis中以原子方式执行
- 避免了多个命令之间的竞态条件
- 不会出现部分执行的情况

**2. 减少网络开销**
- 一次网络往返完成多个操作
- 不使用Lua需要多次Redis命令调用
- 在高并发场景下性能提升明显

**3. 避免并发问题**
```java
// 不使用Lua的问题示例
// 线程1读取库存为1
Integer stock = redis.get("stock"); // stock = 1
// 线程2也读取库存为1
Integer stock2 = redis.get("stock"); // stock = 1

// 两个线程都判断库存充足
if (stock > 0) {
    // 线程1扣减
    redis.decr("stock"); // stock = 0
}
if (stock2 > 0) {
    // 线程2也扣减，库存变成-1，超发！
    redis.decr("stock"); // stock = -1
}
```

**4. 业务逻辑封装**
- 将复杂的判断逻辑放在Redis端执行
- 减少应用层代码复杂度
- 统一库存扣减逻辑，便于维护

**5. 性能优势对比**

| 方案 | 网络往返 | 原子性 | 性能 |
|------|---------|--------|------|
| 多次Redis命令 | 3-5次 | ❌ | 低 |
| Lua脚本 | 1次 | ✅ | 高 |
| 分布式锁+命令 | 2-3次 | ✅ | 中 |

### 3. 数据库与Redis双写策略

```java
@Service
public class CouponStockSyncService {
    
    @Autowired
    private CouponStockMapper stockMapper;
    
    @Autowired
    private StringRedisTemplate redisTemplate;
    
    /**
     * 初始化库存到Redis（系统启动或Redis重启后）
     */
    @PostConstruct
    public void initStockToRedis() {
        List<CouponStock> stockList = stockMapper.selectAllActiveStock();
        
        for (CouponStock stock : stockList) {
            String key = "coupon:stock:" + stock.getTemplateId();
            // 从数据库加载库存到Redis
            redisTemplate.opsForValue().set(key, 
                String.valueOf(stock.getAvailableCount()));
        }
    }
    
    /**
     * 库存扣减（先Redis后数据库）
     */
    @Transactional(rollbackFor = Exception.class)
    public boolean deductStockWithDB(Long templateId, Long userId) {
        String stockKey = "coupon:stock:" + templateId;
        
        try {
            // 1. 先扣减Redis库存
            Long newStock = redisTemplate.opsForValue().decrement(stockKey);
            
            if (newStock < 0) {
                // 库存不足，回滚Redis
                redisTemplate.opsForValue().increment(stockKey);
                return false;
            }
            
            // 2. 扣减数据库库存（乐观锁）
            int rows = stockMapper.deductStock(templateId);
            
            if (rows == 0) {
                // 数据库扣减失败，回滚Redis
                redisTemplate.opsForValue().increment(stockKey);
                return false;
            }
            
            // 3. 异步写入领取记录
            asyncSaveReceiveRecord(templateId, userId);
            
            return true;
            
        } catch (Exception e) {
            log.error("扣减库存异常", e);
            // 回滚Redis
            redisTemplate.opsForValue().increment(stockKey);
            throw e;
        }
    }
}
```

### 4. 异步对账机制

```java
@Component
public class StockReconciliationJob {
    
    @Autowired
    private CouponStockMapper stockMapper;
    
    @Autowired
    private UserCouponMapper userCouponMapper;
    
    @Autowired
    private StringRedisTemplate redisTemplate;
    
    /**
     * 每小时对账一次
     */
    @Scheduled(cron = "0 0 * * * ?")
    public void reconcileStock() {
        List<CouponStock> stockList = stockMapper.selectAllActiveStock();
        
        for (CouponStock dbStock : stockList) {
            Long templateId = dbStock.getTemplateId();
            
            // 1. 从Redis获取库存
            String redisKey = "coupon:stock:" + templateId;
            String redisStockStr = redisTemplate.opsForValue().get(redisKey);
            
            if (redisStockStr == null) {
                // Redis中不存在，从数据库恢复
                redisTemplate.opsForValue().set(redisKey, 
                    String.valueOf(dbStock.getAvailableCount()));
                continue;
            }
            
            Integer redisStock = Integer.parseInt(redisStockStr);
            Integer dbAvailableStock = dbStock.getAvailableCount();
            
            // 2. 比对差异
            if (!redisStock.equals(dbAvailableStock)) {
                log.warn("库存不一致，templateId:{}, Redis:{}, DB:{}", 
                    templateId, redisStock, dbAvailableStock);
                
                // 3. 以数据库为准修正Redis（也可以反向）
                redisTemplate.opsForValue().set(redisKey, 
                    String.valueOf(dbAvailableStock));
                
                // 4. 记录对账日志
                recordReconciliationLog(templateId, redisStock, dbAvailableStock);
            }
        }
    }
    
    /**
     * Redis宕机后的库存重建
     */
    public void rebuildStockFromDB() {
        log.info("开始从数据库重建Redis库存");
        
        // 1. 从数据库查询所有活动的优惠券
        List<CouponStock> stockList = stockMapper.selectAllActiveStock();
        
        // 2. 重新计算实际可用库存
        for (CouponStock stock : stockList) {
            // 实际已领取数量
            Integer receivedCount = userCouponMapper.countByTemplateId(
                stock.getTemplateId());
            
            // 可用库存 = 总库存 - 已领取
            Integer availableCount = stock.getTotalCount() - receivedCount;
            
            if (availableCount < 0) {
                availableCount = 0;
            }
            
            // 3. 更新到Redis
            String key = "coupon:stock:" + stock.getTemplateId();
            redisTemplate.opsForValue().set(key, String.valueOf(availableCount));
            
            log.info("重建库存完成，templateId:{}, 可用库存:{}", 
                stock.getTemplateId(), availableCount);
        }
    }
}
```

### 5. 降级方案

```java
@Service
public class CouponReceiveService {
    
    @Autowired
    private StringRedisTemplate redisTemplate;
    
    @Autowired
    private CouponStockMapper stockMapper;
    
    // 降级开关
    private volatile boolean redisAvailable = true;
    
    /**
     * 领取优惠券（带降级）
     */
    public CouponReceiveResult receiveCoupon(Long templateId, Long userId) {
        if (redisAvailable) {
            try {
                // 正常流程：使用Redis
                return receiveCouponFromRedis(templateId, userId);
            } catch (RedisConnectionException e) {
                log.error("Redis连接失败，切换到降级模式", e);
                redisAvailable = false;
                // 触发告警
                alertRedisDown();
            }
        }
        
        // 降级流程：直接操作数据库
        return receiveCouponFromDB(templateId, userId);
    }
    
    /**
     * 降级方案：直接使用数据库
     */
    @Transactional(rollbackFor = Exception.class)
    private CouponReceiveResult receiveCouponFromDB(Long templateId, Long userId) {
        // 1. 检查用户领取次数（数据库）
        int userReceivedCount = userCouponMapper.countByTemplateIdAndUserId(
            templateId, userId);
        
        CouponTemplate template = templateMapper.selectById(templateId);
        if (userReceivedCount >= template.getPerUserLimit()) {
            return CouponReceiveResult.fail("已达领取上限");
        }
        
        // 2. 扣减库存（数据库乐观锁）
        int rows = stockMapper.deductStockWithLock(templateId);
        if (rows == 0) {
            return CouponReceiveResult.fail("库存不足");
        }
        
        // 3. 生成用户优惠券
        UserCoupon userCoupon = createUserCoupon(templateId, userId);
        userCouponMapper.insert(userCoupon);
        
        return CouponReceiveResult.success(userCoupon);
    }
    
    /**
     * 健康检查，自动恢复
     */
    @Scheduled(fixedDelay = 10000) // 每10秒检查一次
    public void checkRedisHealth() {
        if (!redisAvailable) {
            try {
                redisTemplate.opsForValue().get("health:check");
                log.info("Redis恢复正常，切换回正常模式");
                redisAvailable = true;
                // 触发库存重建
                rebuildStockFromDB();
            } catch (Exception e) {
                log.debug("Redis仍不可用");
            }
        }
    }
}
```

### 故障恢复流程

```
Redis故障
    ↓
自动切换到从节点（Sentinel）
    ↓
若主从都故障
    ↓
触发降级，使用数据库
    ↓
监控检测到Redis恢复
    ↓
从数据库重建Redis库存
    ↓
对账校验
    ↓
切回正常模式
```

```java
@Service
public class DistributedLockPreventService {
    
    @Autowired
    private RedissonClient redissonClient;
    
    /**
     * 使用Redisson分布式锁
     */
    public CouponReceiveResult receiveWithRedissonLock(Long templateId, Long userId) {
        String lockKey = "lock:receive:" + templateId + ":" + userId;
        RLock lock = redissonClient.getLock(lockKey);
        
        try {
            // 尝试加锁，最多等待3秒，锁定10秒后自动释放
            boolean locked = lock.tryLock(3, 10, TimeUnit.SECONDS);
            
            if (!locked) {
                return CouponReceiveResult.fail("操作太频繁");
            }
            
            // 双重检查
            if (hasReceived(templateId, userId)) {
                return CouponReceiveResult.fail("已领取");
            }
            
            // 执行领取逻辑
            return doReceive(templateId, userId);
            
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return CouponReceiveResult.fail("系统繁忙");
        } finally {
            // 释放锁
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
    
    /**
     * 自己实现的简单分布式锁
     */
    public CouponReceiveResult receiveWithSimpleLock(Long templateId, Long userId) {
        String lockKey = "lock:receive:" + templateId + ":" + userId;
        String lockValue = UUID.randomUUID().toString();
        
        try {
            // SET NX EX
            Boolean locked = redisTemplate.opsForValue()
                .setIfAbsent(lockKey, lockValue, 10, TimeUnit.SECONDS);
            
            if (Boolean.FALSE.equals(locked)) {
                return CouponReceiveResult.fail("请勿重复提交");
            }
            
            // 业务逻辑
            return doReceive(templateId, userId);
            
        } finally {
            // Lua脚本安全释放锁
            releaseLock(lockKey, lockValue);
        }
    }
    
    private void releaseLock(String key, String value) {
        String luaScript = 
            "if redis.call('get', KEYS[1]) == ARGV[1] then " +
            "    return redis.call('del', KEYS[1]) " +
            "else " +
            "    return 0 " +
            "end";
        
        DefaultRedisScript<Long> script = new DefaultRedisScript<>();
        script.setScriptText(luaScript);
        script.setResultType(Long.class);
        
        redisTemplate.execute(script, Collections.singletonList(key), value);
    }
}
```

```java
@Service
public class RateLimitPreventService {
    
    /**
     * 使用Guava RateLimiter（单机）
     */

        CacheBuilder.newBuilder()
            .maximumSize(10000)
            .expireAfterAccess(1, TimeUnit.HOURS)
            .build(new CacheLoader<String, RateLimiter>() {
                @Override
                public RateLimiter load(String key) {
                    // 每个用户每秒最多1次请求

                }
            });
    
    public boolean checkRateLimit(Long userId) {
        String key = "user:" + userId;
        try {
            RateLimiter limiter = rateLimiterCache.get(key);
            // 尝试获取令牌，最多等待100ms
            return limiter.tryAcquire(100, TimeUnit.MILLISECONDS);
        } catch (ExecutionException e) {
            log.error("获取限流器失败", e);
            return false;
        }
    }
    
    /**
     * Redis滑动窗口限流
     */
    public boolean checkSlidingWindow(Long templateId, Long userId, int maxCount, int windowSeconds) {
        String key = "limit:receive:" + templateId + ":" + userId;
        long now = System.currentTimeMillis();
        long windowStart = now - windowSeconds * 1000L;
        
        // 1. 删除窗口外的数据
        redisTemplate.opsForZSet().removeRangeByScore(key, 0, windowStart);
        
        // 2. 统计窗口内的请求数
        Long count = redisTemplate.opsForZSet().zCard(key);
        
        if (count != null && count >= maxCount) {
            return false; // 超过限制
        }
        
        // 3. 记录本次请求
        redisTemplate.opsForZSet().add(key, UUID.randomUUID().toString(), now);
        
        // 4. 设置过期时间
        redisTemplate.expire(key, windowSeconds + 10, TimeUnit.SECONDS);
        
        return true;
    }
    
    /**
     * Redis + Lua实现滑动窗口（原子性更好）
     */
    private static final String SLIDING_WINDOW_SCRIPT = 
        "local key = KEYS[1]\n" +
        "local now = tonumber(ARGV[1])\n" +
        "local window = tonumber(ARGV[2])\n" +
        "local maxCount = tonumber(ARGV[3])\n" +
        "local windowStart = now - window * 1000\n" +
        "\n" +
        "redis.call('ZREMRANGEBYSCORE', key, 0, windowStart)\n" +
        "local count = redis.call('ZCARD', key)\n" +
        "\n" +
        "if count >= maxCount then\n" +
        "    return 0\n" +
        "end\n" +
        "\n" +
        "redis.call('ZADD', key, now, now)\n" +
        "redis.call('EXPIRE', key, window + 10)\n" +
        "return 1";
    
    public boolean checkWithLuaSlidingWindow(Long templateId, Long userId, int maxCount, int windowSeconds) {
```

```java
    @Transactional(rollbackFor = Exception.class)
    public CouponReceiveResult receiveWithSelectForUpdate(Long templateId, Long userId) {
        // 悲观锁，锁住用户的领取记录
        List<UserCoupon> coupons = userCouponMapper
            .selectByTemplateAndUserForUpdate(templateId, userId);
        
        if (!coupons.isEmpty()) {
            return CouponReceiveResult.fail("已领取");
        }
        
        // 在事务内执行领取，直到事务提交才释放锁
        return doReceive(templateId, userId);
    }
}
```

### 综合方案（推荐）

```java
@Service
public class ComprehensivePreventService {
    
    /**
     * 多层防护策略
     */
    public CouponReceiveResult receiveWithMultiLayer(Long templateId, Long userId) {
        // 第1层：Redis快速检查（性能最优）
        if (!redisSetService.checkAndMark(templateId, userId)) {
            return CouponReceiveResult.fail("您已领取过该优惠券");
        }
        
        try {
            // 第2层：分布式锁（防止极端并发）
            String lockKey = "lock:receive:" + templateId + ":" + userId;
            return redissonClient.getLock(lockKey).tryLock(3, 10, TimeUnit.SECONDS) 
                ? doReceiveWithDBCheck(templateId, userId)
                : CouponReceiveResult.fail("系统繁忙，请稍后重试");
                
        } catch (Exception e) {
            // 失败回滚Redis标记
            redisSetService.removeMark(templateId, userId);
            throw e;
        }
    }
    
    @Transactional(rollbackFor = Exception.class)
    private CouponReceiveResult doReceiveWithDBCheck(Long templateId, Long userId) {
        try {
            // 第3层：数据库唯一索引（最终保障）
            UserCoupon coupon = buildUserCoupon(templateId, userId);
            userCouponMapper.insert(coupon);
            
            return CouponReceiveResult.success(coupon);
            
        } catch (DuplicateKeyException e) {
            // 唯一索引冲突，这种情况理论上不应该发生
            log.error("多层防护失效，出现数据库唯一索引冲突");
            return CouponReceiveResult.fail("领取失败");
        }
    }
}
```

### 方案选择建议

| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| 一般电商系统 | **Redis Set + 数据库唯一索引** | 性能与可靠性平衡 |
| 高并发秒杀 | **Redis Lua脚本 + 异步DB** | 性能优先 |
| 金融系统 | **数据库唯一索引 + 悲观锁** | 数据强一致性 |
| 小流量系统 | **数据库唯一索引** | 实现简单 |
| 防刷接口 | **限流 + Redis Set** | 综合防护 |

### 完整的防重复领取流程

```
用户点击领取
    ↓
前端防抖（300ms）
    ↓
限流检查（每秒1次）
    ↓
Redis Set快速检查
    ↓
分布式锁（避免极端并发）
    ↓
扣减Redis库存
    ↓
数据库唯一索引插入
    ↓
异步同步到数据库
    ↓
返回领取结果
```

这样的多层防护可以在性能和可靠性之间取得最佳平衡。
