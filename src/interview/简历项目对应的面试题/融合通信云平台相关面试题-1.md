# 融合通信云平台相关面试题-订单与支付模块技术方案详解

## 1. 订单状态一致性与状态机设计

### 订单状态机设计

```java
public enum OrderStatus {
    PENDING_PAYMENT(10, "待支付"),
    PAID(20, "已支付"),
    PROCESSING(30, "处理中"),
    SHIPPED(40, "已发货"),
    COMPLETED(50, "已完成"),
    CANCELLED(90, "已取消"),
    REFUNDING(91, "退款中"),
    REFUNDED(92, "已退款");
    
    private final int code;
    private final String desc;
}

// 状态转换规则定义
public class OrderStateMachine {
    private static final Map<OrderStatus, Set<OrderStatus>> TRANSITIONS = new HashMap<>();
    
    static {
        TRANSITIONS.put(PENDING_PAYMENT, Set.of(PAID, CANCELLED));
        TRANSITIONS.put(PAID, Set.of(PROCESSING, REFUNDING));
        TRANSITIONS.put(PROCESSING, Set.of(SHIPPED, REFUNDING));
        TRANSITIONS.put(SHIPPED, Set.of(COMPLETED, REFUNDING));
        TRANSITIONS.put(REFUNDING, Set.of(REFUNDED));
        // COMPLETED 和 REFUNDED 是终态
    }
    
    public boolean canTransition(OrderStatus from, OrderStatus to) {
        Set<OrderStatus> allowedTransitions = TRANSITIONS.get(from);
        return allowedTransitions != null && allowedTransitions.contains(to);
    }
}
```

### 保证状态一致性的技术方案

**方案一：数据库乐观锁**

```java
@Entity
public class Order {
    @Id
    private Long id;
    
    @Enumerated(EnumType.STRING)
    private OrderStatus status;
    
    @Version
    private Long version;  // 乐观锁版本号
    
    private LocalDateTime updateTime;
}

@Service
public class OrderService {
    
    @Transactional
    public boolean updateOrderStatus(Long orderId, OrderStatus newStatus) {
        // 1. 查询订单
        Order order = orderRepository.findById(orderId)
            .orElseThrow(() -> new OrderNotFoundException());
        
        // 2. 校验状态转换是否合法
        if (!stateMachine.canTransition(order.getStatus(), newStatus)) {
            throw new IllegalStateTransitionException(
                String.format("不允许从 %s 转换到 %s", 
                    order.getStatus(), newStatus)
            );
        }
        
        // 3. 更新状态（乐观锁自动处理并发）
        order.setStatus(newStatus);
        order.setUpdateTime(LocalDateTime.now());
        
        try {
            orderRepository.save(order);
            
            // 4. 发送状态变更事件
            eventPublisher.publish(new OrderStatusChangedEvent(orderId, newStatus));
            
            return true;
        } catch (OptimisticLockingFailureException e) {
            log.warn("订单状态更新冲突，orderId: {}", orderId);
            return false;
        }
    }
}
```

## 2. 支付回调接口幂等性实现

### 完整技术方案

**方案架构**：唯一键去重 + 数据库约束 + 分布式锁

```java
@RestController
@RequestMapping("/payment/callback")
public class PaymentCallbackController {
    
    @Autowired
    private PaymentCallbackService callbackService;
    
    @PostMapping("/alipay")
    public String alipayCallback(@RequestParam Map<String, String> params) {
        try {
            // 1. 验签
            if (!AlipaySignature.rsaCheckV1(params, alipayPublicKey, charset, signType)) {
                return "fail";
            }
            
            // 2. 幂等处理
            boolean success = callbackService.handleCallback(
                params.get("out_trade_no"),    // 商户订单号
                params.get("trade_no"),         // 支付宝交易号
                new BigDecimal(params.get("total_amount")),
                params.get("trade_status")
            );
            
            return success ? "success" : "fail";
        } catch (Exception e) {
            log.error("支付回调处理失败", e);
            return "fail";
        }
    }
}
```

### 核心实现：四层防护

```java
@Service
public class PaymentCallbackService {
    
    @Autowired
    private RedissonClient redissonClient;
    
    @Autowired
    private PaymentRecordRepository paymentRecordRepository;
    
    @Autowired
    private OrderService orderService;
    
    /**
     * 幂等处理支付回调
     */
    @Transactional
    public boolean handleCallback(String orderNo, String tradeNo, 
                                   BigDecimal amount, String tradeStatus) {
        
        // 第一层：分布式锁防并发
        String lockKey = "payment:callback:" + orderNo;
        RLock lock = redissonClient.getLock(lockKey);
        
        try {
            if (!lock.tryLock(5, 30, TimeUnit.SECONDS)) {
                log.warn("获取支付回调锁失败，orderNo: {}", orderNo);
                return false;
            }
            
            try {
                // 第二层：Redis 快速去重
                // 场景：支付宝短时间内发送了 100 次重复回调

                // ❌ 没有 Redis 去重
                // 100 次请求都会：
                // 1. 获取分布式锁（Redis 操作）
                // 2. 执行数据库 INSERT（数据库操作）
                // 3. 捕获唯一键冲突异常
                // 4. 释放锁
                // 结果：99 次无效的数据库操作

                // ✅ 有 Redis 去重
                // 第 1 次：正常处理
                // 第 2-100 次：Redis 层面就返回了，不走数据库
                // 结果：只有 1 次数据库操作
                String dedupeKey = "payment:dedupe:" + tradeNo;
                Boolean isNew = redisTemplate.opsForValue()
                    .setIfAbsent(dedupeKey, "1", 24, TimeUnit.HOURS);
                
                if (Boolean.FALSE.equals(isNew)) {
                    log.info("支付回调重复，已处理过，tradeNo: {}", tradeNo);
                    return true;  // 返回成功，避免第三方重复回调
                }
                
                // 第三层：数据库唯一约束
                PaymentRecord record = new PaymentRecord();
                record.setOrderNo(orderNo);
                record.setTradeNo(tradeNo);  // 唯一索引
                record.setAmount(amount);
                record.setStatus(tradeStatus);
                record.setCallbackTime(LocalDateTime.now());
                
                try {
                    paymentRecordRepository.save(record);
                } catch (DataIntegrityViolationException e) {
                    // 唯一键冲突，说明已处理
                    log.info("支付记录已存在，tradeNo: {}", tradeNo);
                    return true;
                }
                
                // 第四层：订单状态校验
                if ("TRADE_SUCCESS".equals(tradeStatus)) {
                    return processSuccessPayment(orderNo, amount);
                }
                
                return true;
                
            } finally {
                lock.unlock();
            }
            
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return false;
        }
    }
    
    private boolean processSuccessPayment(String orderNo, BigDecimal amount) {
        Order order = orderRepository.findByOrderNo(orderNo)
            .orElseThrow(() -> new OrderNotFoundException());
        
        // 状态校验：只有待支付状态才能转为已支付
        if (order.getStatus() != OrderStatus.PENDING_PAYMENT) {
            log.warn("订单状态不是待支付，无法处理，orderNo: {}, status: {}", 
                orderNo, order.getStatus());
            return true;  // 已处理过，返回成功
        }
        
        // 金额校验
        if (order.getAmount().compareTo(amount) != 0) {
            log.error("支付金额不匹配，orderNo: {}, expected: {}, actual: {}", 
                orderNo, order.getAmount(), amount);
            return false;
        }
        
        // 更新订单状态
        return orderService.updateOrderStatus(order.getId(), OrderStatus.PAID);
    }
}
```

## 3. 支付回调延迟/丢失的最终一致性方案

### 完整解决方案：主动查询 + 消息补偿

**架构设计**：
- 主动查询机制：定时任务轮询未支付订单
- 异步补偿：使用延迟队列或定时任务
- 人工介入：超时订单告警

---

### 方案一：延迟队列方案（详细解析）

#### 核心思路

**问题**：支付宝回调可能延迟或丢失，导致用户已支付但订单状态未更新

**解决**：创建订单后，发送延迟消息到 MQ，到期后主动查询支付宝检查支付状态

#### 完整流程图

```
用户下单支付流程：

1. 创建订单
   ↓
2. 发送 3 条延迟消息到 RabbitMQ
   - 5分钟后检查
   - 15分钟后检查  
   - 30分钟后检查
   ↓
3. 用户跳转支付宝支付
   ↓
4. 支付宝回调（正常情况）
   ↓
5. 订单状态变为"已支付" ✓

异常情况（回调丢失）：

1. 创建订单
   ↓
2. 发送延迟消息（已发送）
   ↓
3. 用户完成支付
   ↓
4. 支付宝回调丢失 ✗
   ↓
5. 订单状态仍是"待支付"
   ↓
6. 5分钟后，延迟消息触发
   ↓
7. 主动调用支付宝查询接口
   ↓
8. 发现已支付，补偿更新订单状态 ✓
```

#### 详细代码实现

**步骤1：创建订单时发送延迟消息**

```java
@Service
public class OrderService {
    
    @Autowired
    private RabbitTemplate rabbitTemplate;
    
    @Autowired
    private OrderRepository orderRepository;
    
    /**
     * 创建订单
     */
    @Transactional
    public Order createOrder(OrderCreateRequest request) {
        // 1. 创建订单
        Order order = new Order();
        order.setOrderNo(generateOrderNo());
        order.setUserId(request.getUserId());
        order.setAmount(request.getAmount());
        order.setStatus(OrderStatus.PENDING_PAYMENT);
        order.setCreateTime(LocalDateTime.now());
        
        order = orderRepository.save(order);
        
        // 2. 发送延迟检查消息（关键步骤）
        schedulePaymentCheck(order.getId());
        
        return order;
    }
    
    /**
     * 发送延迟检查消息
     */
    private void schedulePaymentCheck(Long orderId) {
        // 设置 3 个检查点：5分钟、15分钟、30分钟
        int[] delayMinutes = {5, 15, 30};
        
        for (int i = 0; i < delayMinutes.length; i++) {
            PaymentCheckMessage message = new PaymentCheckMessage();
            message.setOrderId(orderId);
            message.setDelayMinutes(delayMinutes[i]);
            message.setRetryCount(i + 1);  // 第几次检查
            message.setMaxRetry(delayMinutes.length);
            
            // 发送延迟消息
            rabbitTemplate.convertAndSend(
                "payment.check.exchange",      // 交换机
                "payment.check.routing",       // 路由键
                message,
                msg -> {
                    // 设置延迟时间（毫秒）
                    msg.getMessageProperties()
                        .setDelay(delayMinutes[i] * 60 * 1000);
                    return msg;
                }
            );
            
            log.info("发送支付检查延迟消息，orderId: {}, delay: {}分钟", 
                orderId, delayMinutes[i]);
        }
    }
}
```

**步骤3：消费延迟消息，主动查询支付状态**

```java
@Component
public class PaymentCheckConsumer {
    
    @Autowired
    private OrderRepository orderRepository;
    
    @Autowired
    private AlipayQueryService alipayQueryService;
    
    @Autowired
    private PaymentCallbackService callbackService;
    
    @Autowired
    private AlertService alertService;
    
    /**
     * 消费延迟消息
     */
    @RabbitListener(queues = "payment.check.queue")
    public void handlePaymentCheck(PaymentCheckMessage message) {
        Long orderId = message.getOrderId();
        
        log.info("开始检查支付状态，orderId: {}, 第{}次检查", 
            orderId, message.getRetryCount());
        
        try {
            // 1. 查询订单
            Order order = orderRepository.findById(orderId)
                .orElse(null);
            
            if (order == null) {
                log.warn("订单不存在，orderId: {}", orderId);
                return;
            }
            
            // 2. 如果订单已支付，不需要检查
            if (order.getStatus() != OrderStatus.PENDING_PAYMENT) {
                log.info("订单已处理，无需检查，orderId: {}, status: {}", 
                    orderId, order.getStatus());
                return;
            }
            
            // 3. 主动查询支付宝（关键步骤）
            PaymentQueryResult result = alipayQueryService
                .queryPaymentStatus(order.getOrderNo());
            
            // 4. 处理查询结果
            if (result == null) {
                log.warn("查询支付宝失败，orderId: {}", orderId);
                handleQueryFailure(message, order);
                return;
            }
            
            if (result.isPaid()) {
                // 发现已支付，补偿处理
                log.warn("发现支付回调丢失，订单实际已支付，orderId: {}", orderId);
                
                // "模拟支付回调" = 调用本地业务代码处理，更新本地订单状态
                boolean success = callbackService.handleCallback(
                    order.getOrderNo(),
                    result.getTradeNo(),
                    result.getAmount(),
                    "TRADE_SUCCESS"
                );
                
                if (success) {
                    log.info("支付状态补偿成功，orderId: {}", orderId);
                    
                    // 发送告警通知
                    alertService.sendPaymentCallbackLostAlert(order);
                } else {
                    log.error("支付状态补偿失败，orderId: {}", orderId);
                }
                
            } else {
                // 未支付
                log.info("订单仍未支付，orderId: {}, 第{}次检查", 
                    orderId, message.getRetryCount());
                
                // 最后一次检查仍未支付，发送告警
                if (message.getRetryCount() >= message.getMaxRetry()) {
                    alertService.sendUnpaidOrderAlert(order);
                }
            }
            
        } catch (Exception e) {
            log.error("检查支付状态失败，orderId: {}", orderId, e);
            handleQueryFailure(message, order);
        }
    }
    
    /**
     * 处理查询失败
     */
    private void handleQueryFailure(PaymentCheckMessage message, Order order) {
        // 最后一次检查失败，发送告警
        if (message.getRetryCount() >= message.getMaxRetry()) {
            alertService.sendPaymentCheckFailureAlert(order);
        }
    }
}
```

#### 时序图

```
时间轴：                  0分钟      5分钟      15分钟     30分钟
                         |----------|----------|----------|
创建订单                  ✓
发送延迟消息              ✓
用户支付                        ✓
支付宝回调丢失 ✗                 ✗

延迟消息1触发                          ✓
主动查询支付宝                         ✓
发现已支付                             ✓
补偿更新订单                           ✓
问题解决 ✓

延迟消息2触发                                   ✓
发现已处理，忽略                                ✓

延迟消息3触发                                            ✓
发现已处理，忽略                                         ✓
```

#### 关键点说明

1. **为什么发 3 条消息？**
   - 第1次（5分钟）：快速发现问题
   - 第2次（15分钟）：兜底检查
   -第3次（30分钟）：最终确认，超时则告警

2. **消息会不会重复消费？**
   - 不会，消费时先检查订单状态
   - 如果已支付，直接返回

3. **如果订单真的未支付？**
   - 3次检查都会发现未支付
   - 最后一次发送告警通知运营，进入取消订单环节

### 方案二：定时任务扫描（简单场景）

```java
@Component
public class PaymentCheckTask {
    
    /**
     * 每分钟扫描一次超过5分钟未支付的订单
     */
    @Scheduled(cron = "0 */1 * * * ?")
    public void checkPendingOrders() {
        LocalDateTime threshold = LocalDateTime.now().minusMinutes(5);
        
        List<Order> pendingOrders = orderRepository
            .findByStatusAndCreateTimeBefore(
                OrderStatus.PENDING_PAYMENT, 
                threshold
            );
        
        for (Order order : pendingOrders) {
            // 主动查询支付状态
            try {
                PaymentQueryResult result = queryPaymentStatus(order.getOrderNo());
                
                if (result.isPaid()) {
                    // 补偿处理
                    callbackService.handleCallback(
                        order.getOrderNo(),
                        result.getTradeNo(),
                        result.getAmount(),
                        "TRADE_SUCCESS"
                    );
                }
            } catch (Exception e) {
                log.error("主动查询支付状态失败，orderId: {}", order.getId(), e);
            }
        }
    }
}
```

### 方案三：支付宝主动查询接口（详细解析）

#### 支付宝提供的查询接口

支付宝提供了 `alipay.trade.query` 接口，可以主动查询订单的支付状态。

#### 接口调用代码

```java
@Service
public class AlipayQueryService {
    
    @Autowired
    private AlipayClient alipayClient;
    
    /**
     * 查询支付宝订单状态
     * 
     * @param orderNo 商户订单号
     * @return 支付查询结果
     */
    public PaymentQueryResult queryPaymentStatus(String orderNo) {
        
        // 1. 构造请求对象
        AlipayTradeQueryRequest request = new AlipayTradeQueryRequest();
        
        // 2. 设置业务参数
        JSONObject bizContent = new JSONObject();
        bizContent.put("out_trade_no", orderNo);  // 商户订单号
        // 也可以用支付宝交易号查询：
        // bizContent.put("trade_no", alipayTradeNo);
        
        request.setBizContent(bizContent.toString());
        
        try {
            // 3. 发起请求
            AlipayTradeQueryResponse response = alipayClient.execute(request);
            
            // 4. 判断调用是否成功
            if (!response.isSuccess()) {
                log.warn("查询支付宝订单失败，orderNo: {}, code: {}, msg: {}", 
                    orderNo, response.getCode(), response.getMsg());
                return PaymentQueryResult.failed(response.getMsg());
            }
            
            // 5. 解析交易状态
            String tradeStatus = response.getTradeStatus();
            
            log.info("查询支付宝订单成功，orderNo: {}, tradeStatus: {}", 
                orderNo, tradeStatus);
            
            // 6. 构造返回结果
            return PaymentQueryResult.builder()
                .success(true)
                .paid(isTradeSuccess(tradeStatus))
                .tradeNo(response.getTradeNo())
                .buyerLogonId(response.getBuyerLogonId())
                .totalAmount(new BigDecimal(response.getTotalAmount()))
                .tradeStatus(tradeStatus)
                .build();
            
        } catch (AlipayApiException e) {
            log.error("调用支付宝查询接口异常，orderNo: {}", orderNo, e);
            return PaymentQueryResult.failed("接口调用异常: " + e.getMessage());
        }
    }
    
    /**
     * 判断交易是否成功
     */
    private boolean isTradeSuccess(String tradeStatus) {
        // WAIT_BUYER_PAY: 交易创建，等待买家付款
        // TRADE_CLOSED: 未付款交易超时关闭，或支付完成后全额退款
        // TRADE_SUCCESS: 交易支付成功
        // TRADE_FINISHED: 交易结束，不可退款
        
        return "TRADE_SUCCESS".equals(tradeStatus) 
            || "TRADE_FINISHED".equals(tradeStatus);
    }
}
```

```java
        } else {

            log.info("订单未支付，orderNo: {}", order.getOrderNo());
        }
```

```java
            "order.delay.exchange",
            "order.cancel",
            message,
            msg -> {

                return msg;

            orderId, timeoutMinutes);

    public void cancelOrder(OrderCancelMessage message) {
        Long orderId = message.getOrderId();
        
        Order order = orderRepository.findById(orderId)
            .orElse(null);

            log.warn("订单不存在，orderId: {}", orderId);
            return;

        // 只取消待支付状态的订单
        if (order.getStatus() == OrderStatus.PENDING_PAYMENT) {
            boolean success = orderService.updateOrderStatus(
                orderId, 
                OrderStatus.CANCELLED

            if (success) {
                // 释放库存
                inventoryService.releaseStock(order);

                    couponService.releaseCoupon(order.getCouponId());

            }
        } else {
```

```java
     * 加法

        if (b == null) b = BigDecimal.ZERO;

        if (b == null || b.compareTo(BigDecimal.ZERO) == 0) {

        }
        return a.divide(b, 2, RoundingMode.HALF_UP);
    }

    public static boolean greaterThan(BigDecimal a, BigDecimal b) {

    }
    
    /**

    public static Long yuanToFen(BigDecimal yuan) {
```

```java
@Service
public class OrderAmountCalculator {
    
    /**
     * 计算订单应付金额
     */
    public OrderAmountDTO calculateOrderAmount(OrderCalculateRequest request) {
        
        // 1. 计算商品总额
        BigDecimal goodsAmount = BigDecimal.ZERO;
        for (OrderItem item : request.getItems()) {
            BigDecimal itemAmount = MoneyCalculator.multiply(
                item.getPrice(), 
                new BigDecimal(item.getQuantity())
            );
            goodsAmount = MoneyCalculator.add(goodsAmount, itemAmount);
        }
        
        // 2. 计算运费
        BigDecimal freightAmount = calculateFreight(request);
        
        // 3. 计算优惠金额
        BigDecimal discountAmount = BigDecimal.ZERO;
        
        // 优惠券
        if (request.getCouponId() != null) {
            Coupon coupon = couponService.getCoupon(request.getCouponId());
            discountAmount = MoneyCalculator.add(
                discountAmount, 
                calculateCouponDiscount(coupon, goodsAmount)
            );
        }
        
        // 满减活动
        if (request.getPromotionId() != null) {
            BigDecimal promotionDiscount = calculatePromotionDiscount(
                request.getPromotionId(), 
                goodsAmount
            );
            discountAmount = MoneyCalculator.add(
                discountAmount, 
                promotionDiscount
            );
        }
        
        // 4. 计算应付金额（商品总额 + 运费 - 优惠）
        BigDecimal payableAmount = MoneyCalculator.add(goodsAmount, freightAmount);
        payableAmount = MoneyCalculator.subtract(payableAmount, discountAmount);
        
        // 5. 金额校验
        if (payableAmount.compareTo(BigDecimal.ZERO) < 0) {
            payableAmount = BigDecimal.ZERO;
        }
        
        return OrderAmountDTO.builder()
            .goodsAmount(goodsAmount)
            .freightAmount(freightAmount)
            .discountAmount(discountAmount)
            .payableAmount(payableAmount)
            .build();
    }
    
    /**
     * 计算优惠券折扣
     */
    private BigDecimal calculateCouponDiscount(Coupon coupon, BigDecimal goodsAmount) {
        if (coupon.getType() == CouponType.FIXED) {
            // 固定金额优惠券
            return coupon.getAmount();
            
        } else if (coupon.getType() == CouponType.RATE) {
            // 折扣券（例如：8折 = 0.8）
            BigDecimal discount = MoneyCalculator.multiply(
                goodsAmount,
                BigDecimal.ONE.subtract(coupon.getRate())
            );
            
            // 最大优惠金额限制
            if (coupon.getMaxDiscountAmount() != null) {
                return discount.min(coupon.getMaxDiscountAmount());
            }
            
            return discount;
        }
        
        return BigDecimal.ZERO;
    }
}
```

```java
    /**
     * 校验支付金额

    public void validatePaymentAmount(Order order, BigDecimal paidAmount) {

        if (order.getPayableAmount().compareTo(paidAmount) != 0) {
            throw new PaymentAmountMismatchException(
```

2. **支付回调幂等**：四层防护（分布式锁 + Redis去重 + 数据库唯一约束 + 状态校验）
3. **最终一致性**：主动查询 + 延迟队列补偿 + 监控告警
4. **订单超时取消**：RabbitMQ延迟队列（推荐）或 Redisson 延迟队列
5. **金额精度**：全局使用 BigDecimal，禁用 float/double，元转分处理

### 技术选型建议

- **订单量 < 10万/天**：定时任务扫描
- **订单量 10万-100万/天**：RabbitMQ 延迟队列
- **订单量 > 100万/天**：Redisson 延迟队列 + 分库分表

这套方案在实际生产环境中经过验证，可以有效保证订单和支付系统的数据一致性和可靠性。
