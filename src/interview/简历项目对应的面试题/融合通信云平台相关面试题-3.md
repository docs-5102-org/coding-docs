# 融合通信云平台相关面试题-微服务架构（5题）

## 11. 服务边界梳理与拆分原则

### 服务边界梳理方法

**1. 业务领域驱动（DDD）**
```
用户域 → 用户服务
├── 用户信息管理
├── 用户认证
└── 用户权限

订单域 → 订单服务
├── 订单创建
├── 订单状态管理
└── 订单查询

商品域 → 商品服务
├── 商品信息
├── 库存管理
└── 价格管理
```

**2. 实际拆分步骤**
```java
// 第一步：识别核心业务实体和聚合根
@Entity
public class Order {  // 聚合根
    private Long id;
    private List<OrderItem> items;  // 聚合内实体
    private OrderStatus status;
    private User user;  // 外部引用，只保存ID
}

// 第二步：定义限界上下文
// 订单上下文
public interface OrderService {
    Order createOrder(OrderDTO dto);
    void cancelOrder(Long orderId);
}

// 商品上下文
public interface ProductService {
    Product getProduct(Long productId);
    boolean checkStock(Long productId, Integer quantity);
}
```

### 核心拆分原则

**1. 单一职责原则**
```yaml
# 好的拆分
用户服务: 
  - 专注用户信息、认证、权限
  
订单服务:
  - 专注订单流程管理
  
# 避免的拆分
用户订单服务:  # ❌ 职责不清晰
  - 用户管理
  - 订单管理
```

**2. 高内聚低耦合**
```java
// 高内聚示例：订单服务内部
@Service
public class OrderService {
    @Autowired
    private OrderRepository orderRepository;
    @Autowired
    private OrderItemRepository orderItemRepository;
    @Autowired
    private OrderValidator validator;
    
    // 订单相关逻辑都在此服务内
    public Order createOrder(OrderDTO dto) {
        validator.validate(dto);
        Order order = buildOrder(dto);
        orderRepository.save(order);
        return order;
    }
}

// 低耦合示例：通过接口调用其他服务
@Service
public class OrderService {
    @Autowired
    private ProductFeignClient productClient;  // 远程调用
    
    public Order createOrder(OrderDTO dto) {
        // 只通过接口与商品服务交互
        Product product = productClient.getProduct(dto.getProductId());
        // ...
    }
}
```

**3. 业务独立性原则**
```
支付服务 → 独立部署、独立数据库
├── 可以独立开发迭代
├── 故障不影响其他服务
└── 可以独立扩缩容
```

**4. 数据独立性原则**
```
每个服务拥有独立数据库：

order_db:
  - orders 表
  - order_items 表

product_db:
  - products 表
  - inventory 表

❌ 避免跨服务直接访问数据库
✅ 通过服务接口获取数据
```

## 12. 为什么选择 Nacos？对比 Eureka

### Nacos 的核心优势

**1. 功能对比**

| 特性 | Nacos | Eureka |
|------|-------|--------|
| 服务注册发现 | ✅ | ✅ |
| 配置管理 | ✅ | ❌ |
| 健康检查 | TCP/HTTP/MySQL | HTTP |
| 负载均衡 | ✅ | ✅ |
| 动态配置推送 | ✅ | ❌ |
| AP/CP模式 | 支持切换 | 仅AP |
| 多数据中心 | ✅ | ❌ |

### Nacos 相比 Eureka 的实际优势

**1. 一站式解决方案**
```
Eureka 方案:
  - Eureka Server (注册中心)
  - Config Server (配置中心)
  - Bus (配置刷新)
  需要维护多个组件

Nacos 方案:
  - Nacos Server 
  一个组件搞定所有
```

**2. 性能更好**
```
Nacos:
  - 支持几万服务实例
  - 毫秒级推送
  - 支持大规模集群

Eureka:
  - 几千服务实例后性能下降
  - 拉取模式延迟较高
```

**3. 运维友好**
```java
// Nacos 提供完善的控制台
- 服务列表管理
- 配置在线编辑
- 实时监控
- 权限控制
- 操作审计

// Eureka 控制台功能有限
- 只能查看服务状态
- 无法编辑配置
```

## 13. Sentinel 限流、熔断、降级配置

### 限流规则配置

**1. QPS 限流**
```java
@RestController
public class OrderController {
    
    @GetMapping("/order/create")
    @SentinelResource(
        value = "createOrder",
        blockHandler = "handleBlock",
        fallback = "handleFallback"
    )
    public Result createOrder(@RequestBody OrderDTO dto) {
        return orderService.createOrder(dto);
    }
    
    // 限流处理方法
    public Result handleBlock(OrderDTO dto, BlockException ex) {
        return Result.fail("系统繁忙，请稍后再试");
    }
    
    // 降级处理方法
    public Result handleFallback(OrderDTO dto, Throwable ex) {
        return Result.fail("服务异常，请稍后重试");
    }
}

// 配置限流规则
@Configuration
public class SentinelConfig {
    @PostConstruct
    public void initFlowRules() {
        List<FlowRule> rules = new ArrayList<>();
        
        // QPS限流：每秒最多100个请求
        FlowRule rule = new FlowRule();
        rule.setResource("createOrder");
        rule.setGrade(RuleConstant.FLOW_GRADE_QPS);
        rule.setCount(100);
        rule.setStrategy(RuleConstant.STRATEGY_DIRECT);
        rule.setControlBehavior(RuleConstant.CONTROL_BEHAVIOR_DEFAULT);
        
        rules.add(rule);
        FlowRuleManager.loadRules(rules);
    }
}
```

## 14. 微服务间调用方式

### Feign vs RestTemplate

**1. Feign 声明式调用（推荐）**
```java
// 定义Feign客户端接口
@FeignClient(
    name = "product-service",
    fallback = ProductClientFallback.class,
    configuration = FeignConfig.class
)
public interface ProductClient {
    
    @GetMapping("/product/{id}")
    Product getProduct(@PathVariable("id") Long id);
    
    @PostMapping("/product/deduct-stock")
    Result deductStock(@RequestBody StockDTO dto);
    
    @GetMapping("/product/list")
    List<Product> getProducts(@RequestParam("ids") List<Long> ids);
}

// 降级实现
@Component
public class ProductClientFallback implements ProductClient {
    
    @Override
    public Product getProduct(Long id) {
        log.warn("商品服务调用失败，返回默认商品");
        return Product.getDefault();
    }
    
    @Override
    public Result deductStock(StockDTO dto) {
        return Result.fail("库存扣减失败");
    }
    
    @Override
    public List<Product> getProducts(List<Long> ids) {
        return Collections.emptyList();
    }
}

// 使用Feign客户端
@Service
public class OrderService {
    
    @Autowired
    private ProductClient productClient;
    
    public Order createOrder(OrderDTO dto) {
        // 直接调用，像本地方法一样
        Product product = productClient.getProduct(dto.getProductId());
        
        if (product == null) {
            throw new BusinessException("商品不存在");
        }
        
        // 扣减库存
        Result result = productClient.deductStock(
            new StockDTO(dto.getProductId(), dto.getQuantity())
        );
        
        if (!result.isSuccess()) {
            throw new BusinessException("库存不足");
        }
        
        // 创建订单
        return saveOrder(dto, product);
    }
}
```

**2. RestTemplate 手动调用**
```java
@Configuration
public class RestTemplateConfig {
    
    @LoadBalanced  // 支持服务名调用
    @Bean
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }
}

@Service
public class OrderService {
    
    @Autowired
    private RestTemplate restTemplate;
    
    @Autowired
    private DiscoveryClient discoveryClient;
    
    public Order createOrder(OrderDTO dto) {
        // 方式1：使用服务名（需要@LoadBalanced）
        String url = "http://product-service/product/" + dto.getProductId();
        Product product = restTemplate.getForObject(url, Product.class);
        
        // 方式2：手动负载均衡
        List<ServiceInstance> instances = 
            discoveryClient.getInstances("product-service");
        
        if (instances.isEmpty()) {
            throw new BusinessException("商品服务不可用");
        }
        
        ServiceInstance instance = instances.get(0);
        String manualUrl = String.format("http://%s:%d/product/%d",
            instance.getHost(), instance.getPort(), dto.getProductId());
        
        product = restTemplate.getForObject(manualUrl, Product.class);
        
        return saveOrder(dto, product);
    }
}
```

### 服务调用失败处理

**1. 重试机制**
```java
// Feign重试配置
@Configuration
public class FeignConfig {
    
    @Bean
    public Retryer feignRetryer() {
        // 最大重试3次，初始间隔100ms，最大间隔1秒
        return new Retryer.Default(100, 1000, 3);
    }
}

// 自定义重试逻辑
@Component
public class CustomRetryer implements Retryer {
    
    private int attempt = 1;
    private final int maxAttempts = 3;
    
    @Override
    public void continueOrPropagate(RetryableException e) {
        if (attempt++ >= maxAttempts) {
            throw e;
        }
        
        try {
            long interval = (long) Math.pow(2, attempt) * 100;
            Thread.sleep(interval);
        } catch (InterruptedException ignored) {
            Thread.currentThread().interrupt();
        }
    }
}
```

```java
@FeignClient(
    name = "user-service",
    fallbackFactory = UserClientFallbackFactory.class
)
public interface UserClient {

    User getUser(@PathVariable Long id);
}

// 降级工厂，可以获取异常信息
@Component
public class UserClientFallbackFactory implements FallbackFactory<UserClient> {
    
    @Override
    public UserClient create(Throwable cause) {
        return new UserClient() {
            @Override
            public User getUser(Long id) {
                log.error("用户服务调用失败: {}", cause.getMessage());
                
                // 根据异常类型做不同处理
                if (cause instanceof TimeoutException) {
                    return User.getTimeoutUser();
                } else if (cause instanceof ConnectException) {
                    return User.getUnavailableUser();
                }
                
                return User.getDefaultUser();
            }
        };
    }
}
```

**4. 全局异常处理**
```java
@ControllerAdvice
public class GlobalExceptionHandler {
    
    @ExceptionHandler(FeignException.class)
    public Result handleFeignException(FeignException e) {
        log.error("Feign调用异常", e);
        
        int status = e.status();
        if (status == 404) {
            return Result.fail("服务不存在");
        } else if (status == 500) {
            return Result.fail("服务内部错误");
        } else if (status == 503) {
            return Result.fail("服务暂时不可用");
        }
        
        return Result.fail("服务调用失败");
    }
    
    @ExceptionHandler(RetryableException.class)
    public Result handleRetryException(RetryableException e) {
        log.error("重试失败", e);
        return Result.fail("服务繁忙，请稍后重试");
    }
}
```

## 15. 分布式事务解决方案

### 方案对比

| 方案 | 一致性 | 性能 | 复杂度 | 适用场景 |
|-----|--------|------|--------|---------|
| Seata AT | 强一致 | 中 | 低 | 金融、支付 |
| TCC | 强一致 | 高 | 高 | 核心交易 |
| 消息最终一致性 | 最终一致 | 高 | 中 | 订单、积分 |
| Saga | 最终一致 | 高 | 中 | 长流程 |

### 1. Seata AT模式（推荐）

```java
// 配置Seata
@Configuration
public class SeataConfig {
    // application.yml
    /*
    seata:
      enabled: true
      application-id: order-service
      tx-service-group: my_tx_group
      service:
        vgroup-mapping:
          my_tx_group: default
      registry:
        type: nacos
        nacos:
          server-addr: 192.168.1.100:8848
    */
}

// 订单服务（事务发起方）
@Service
public class OrderService {
    
    @Autowired
    private OrderMapper orderMapper;
    
    @Autowired
    private ProductClient productClient;
    
    @Autowired
    private AccountClient accountClient;
    
    @GlobalTransactional(
        name = "create-order",
        rollbackFor = Exception.class,
        timeoutMills = 30000
    )
    public Order createOrder(OrderDTO dto) {
        // 1. 创建订单
        Order order = new Order();
        order.setUserId(dto.getUserId());
        order.setProductId(dto.getProductId());
        order.setAmount(dto.getAmount());
        orderMapper.insert(order);
        
        // 2. 扣减库存（远程调用）
        productClient.deductStock(dto.getProductId(), dto.getQuantity());
        
        // 3. 扣减账户余额（远程调用）
        accountClient.deductBalance(dto.getUserId(), dto.getAmount());
        
        // 任何一步失败，自动回滚所有操作
        return order;
    }
}

// 商品服务（事务参与方）
@Service
public class ProductService {
    
    @Autowired
    private ProductMapper productMapper;
    
    @Transactional  // 本地事务，由Seata管理
    public void deductStock(Long productId, Integer quantity) {
        Product product = productMapper.selectById(productId);
        
        if (product.getStock() < quantity) {
            throw new BusinessException("库存不足");
        }
        
        product.setStock(product.getStock() - quantity);
        productMapper.updateById(product);
    }
}

// 账户服务（事务参与方）
@Service
public class AccountService {
    
    @Autowired
    private AccountMapper accountMapper;
    
    @Transactional
    public void deductBalance(Long userId, BigDecimal amount) {
        Account account = accountMapper.selectById(userId);
        
        if (account.getBalance().compareTo(amount) < 0) {
            throw new BusinessException("余额不足");
        }
        
        account.setBalance(account.getBalance().subtract(amount));
        accountMapper.updateById(account);
    }
}
```

```java
// TCC实现
@Service
public class AccountTccActionImpl implements AccountTccAction {
    
    @Autowired
    private AccountMapper accountMapper;
    
    @Autowired
    private AccountFreezeMapper freezeMapper;
    
    @Override
    public boolean prepare(BusinessActionContext context, Long userId, BigDecimal amount) {
        // Try阶段：冻结金额
        Account account = accountMapper.selectById(userId);
        
        if (account.getBalance().compareTo(amount) < 0) {
            return false;
        }
        
        // 创建冻结记录
        AccountFreeze freeze = new AccountFreeze();
        freeze.setUserId(userId);
        freeze.setAmount(amount);
        freeze.setXid(context.getXid());
        freeze.setState("TRYING");
        freezeMapper.insert(freeze);
        
        // 冻结金额
        account.setBalance(account.getBalance().subtract(amount));
        account.setFrozenAmount(account.getFrozenAmount().add(amount));
        accountMapper.updateById(account);
        
        return true;
    }
    
    @Override
    public boolean commit(BusinessActionContext context) {
        // Confirm阶段：确认扣款
        String xid = context.getXid();
        AccountFreeze freeze = freezeMapper.selectByXid(xid);
        
        if (freeze == null || "CONFIRMED".equals(freeze.getState())) {
            return true;  // 幂等性
        }
        
        // 扣减冻结金额
        Account account = accountMapper.selectById(freeze.getUserId());
        account.setFrozenAmount(account.getFrozenAmount().subtract(freeze.getAmount()));
        accountMapper.updateById(account);
        
        // 更新冻结记录状态
        freeze.setState("CONFIRMED");
        freezeMapper.updateById(freeze);
        
        return true;
    }
    
    @Override
    public boolean rollback(BusinessActionContext context) {
        // Cancel阶段：解冻金额
        String xid = context.getXid();
        AccountFreeze freeze = freezeMapper.selectByXid(xid);
        
        if (freeze == null || "CANCELLED".equals(freeze.getState())) {
            return true;  // 幂等性
        }
        
        // 恢复余额
        Account account = accountMapper.selectById(freeze.getUserId());
        account.setBalance(account.getBalance().add(freeze.getAmount()));
        account.setFrozenAmount(account.getFrozenAmount().subtract(freeze.getAmount()));
        accountMapper.updateById(account);
        
        // 更新冻结记录状态
        freeze.setState("CANCELLED");
        freezeMapper.updateById(freeze);
        
        return true;
    }
}
```

## 总结

**微服务拆分**：基于DDD（Domain-Driven Design（领域驱动设计）），遵循单一职责、高内聚低耦合原则

**Nacos选择**：一站式解决注册+配置，性能好，运维友好

**Sentinel使用**：QPS限流、慢调用熔断、异常降级，保护系统稳定

**服务调用**：优先Feign（简洁），配合重试、超时、降级机制

**分布式事务**：根据场景选择Seata/TCC/消息，平衡一致性和性能
